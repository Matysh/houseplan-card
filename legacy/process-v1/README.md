# Legacy process scaffolding

Снимок старой обвязки, выведенной из использования при переключении #1105.
Эти workflows, hooks, скрипты, тесты и инструкции не являются частью действующего процесса.
Не запускайте их для подготовки, ревью, слияния или выпуска. Вход: [PROCESS.md](../../PROCESS.md).

Сохранены исходные относительные пути для разбора истории. Импорты внутри архива не переносились:
это исторический снимок, а не второй работающий конвейер. Git-история и исходные refs записаны в
[отчёте переключения](../../process-next/evidence/cutover-status.md).
