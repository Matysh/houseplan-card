## Что проверено и корректно

- M1 закрыта по существу: новый механизм действительно перебирает **все**
  сохранённые фикстуры и демо-стенд (не только целевую фикстуру 845), фиксирует

  не хватало по тексту r1.
- Защита от «тихого прохода»: отсутствие ожидаемого каталога/CFG, ошибка
  импорта и новый неподписанный конфиг explicitly не превращаются в skip —
  закрывает типовой риск нечувствительного регрессионного теста.
- Указаны отрицательные пробы самого guard (перестановка двух id каталога,
  смена одной связи комнаты/проёма, обратный продуктовый компаратор) — это и
  есть «чем краснеет» для AC4/AC8, которого не хватало в r1.

  меняет результат) явно снята отдельной оговоркой — без неё редакция 4 сама
  создавала бы новое противоречие; автор её предусмотрел.
- Построчные ссылки на `test/model-invariants.test.mjs` (образец механизма) и
  `src/wall-node-history.ts` (уже слитые #842/#843) подтверждены дословно,
  включая i18n-текст посимвольно.
- `stable-fix` в release-артефактах остаётся обоснованным: материал не
  изменился, `git diff --stat v1.80.1 HEAD` по четырём файлам поверхности
  пуст на актуальном SHA.

  заголовку и содержанию, а не из столбца «Доказательство» построчно. Это не
  создаёт неоднозначности (единственный кандидат-механизм для «весь корпус, не
  переименовать») и не требует возврата автору — снимаю как Low, достаточно
  учесть при ревью кода: доказательство AC4/AC8 должно явно называть этот файл
  тестов.
