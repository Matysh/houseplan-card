## Что проверено и корректно

- **AC4, часть 2 (юнит на `subscribeLanguageLoadFailures`)** — ранее
  единственный незакрытый пункт АС4. Текст ТЗ требует «подписка получает
  код, отписка работает»: новый тест (`test/i18n-runtime.test.mjs:173-191`)
  вызывает `notifyLanguageLoadFailures('de')` и проверяет, что оба живых
  подписчика получают код (`['de', '2:de']`), что отписанный слушатель
  замолкает, а второй продолжает получать (`['de', '2:de', '2:de']`), и что
  после отписки обоих доставок больше нет. Проверено автотестом — сам
  прогнал `node --test --test-name-pattern="#354" test/i18n-runtime.test.mjs`
  внутри `mutation-gate` (гейт печатает «чистый прогон» перед мутацией) —
  зелёный. Adversarial-часть: мутант `locale-failure-delivery-cut` заменяет
  ровно ту строку `for (const listener of languageLoadFailureListeners)
  listener(code);`, которой в r1 я вручную ломал доставку и юниты этого не
  замечали — теперь красит юнит (1/1, воспроизведено мной запуском
  `node scripts/mutation-gate.mjs --id=locale-failure-delivery-cut`).
  Дисциплина «тест умеет падать» соблюдена не на словах автора, а моим
  собственным прогоном.
- **Контракт-юнит теперь пиннит и саму разводку**: новая ассерция в
  `test/i18n-runtime.test.mjs:146-150` матчит источник на
  `new LanguageRuntime(LANGUAGE_REGISTRY, BUILD_FINGERPRINT, console.warn,
  notifyLanguageLoadFailures,)` — если кто-то вернёт инлайн-стрелку без
  фан-аута наружу, юнит покраснеет раньше мутационного гейта. Проверено
  чтением и совпадением с текущим `src/i18n/registry.ts:73-79`.
- **L1-фикс не переизобретает формулировку**: оба абзаца
  (`docs/USER-GUIDE.md:149-153`, `docs/USER-GUIDE.ru.md:155-158`) описывают
  тот же сценарий («обе попытки не удались») и добавляют одно предложение
  про тост, не меняя остального текста — проверено построчным диффом.
- **User-Visible: no обоснован по существу**, не только по трейлеру: дельта
  не меняет ни один пользовательский артефакт (текст тоста, ключи локалей,
  условия его появления) — только внутреннее имя функции и тестовую/
  документационную обвязку. Changelog оставлен нетронутым правомерно.
- **Генерируемые копии бандла**: после `npm run build && npm run
  bundle:sync` рабочее дерево чистое — три копии синхронны с
  закоммиченным состоянием на `HEAD`.
- **Регенерация docs-фингерпринта корректна**: `sourceFingerprint` в
  `docs/images/screenshots.json` пересчитан автором в том же коммите
  (потому что `src/i18n/registry.ts` входит в покрытие отпечатка) и
  `check-docs.mjs` подтверждает его актуальность — не унаследованный
  зелёный статус из r1, а новый, пересчитанный под `c1356fae`.
- **«Одно число — один источник»**: дельта не добавляет и не меняет ни
  одну пользователю видимую величину (тот же текст тоста, что и в r1) —
  правило не применимо.
