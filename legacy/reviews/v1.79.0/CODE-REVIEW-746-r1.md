### Разбор по коду (проверено чтением, не исполнением)

Для каждого изменённого блока: произведение «альфа цвета × *-opacity» в покое
не меняется, а при переходе оба сомножителя теперь монотонны от 0 (или от
другого конца) к цели, поэтому продукт двух неубывающих/невозрастающих
кривых ограничен большим из концов — перелёта быть не может:

- `.room.overlay`: было `fill: transparent` (альфа 0, `fill-opacity` по
  умолчанию 1) → стало `fill: transparent; fill-opacity: 0` — продукт 0 в
  обоих случаях, при переходе к `.styled` оба множителя (альфа цвета и
  opacity) растут от 0 монотонно → продукт ограничен произведением конечных
  значений, перелёта нет. Симметрично для `stroke`.
- `.room.yard`: было `fill: rgba(75, 140, 90, 0.14)` (продукт 0.14) → стало
  `fill: rgb(75, 140, 90); fill-opacity: 0.14` (продукт 0.14) — рест не
  меняется, подтверждено прогоном (`rest.yard.fill = ["rgb(75, 140, 90)",
  0.14]`).
- `.room.outlined`: `rgba(62,166,255,0.06)`/`0.55` → `rgb(...); fill-opacity:
  0.06` / `stroke-opacity: 0.55` — рест не меняется (подтверждено прогоном).
- `.room.picked`: `rgba(255,193,77,0.25)` → `rgb(...); fill-opacity: 0.25`;
  `stroke: #ffc14d` (уже непрозрачный) получил явный `stroke-opacity: 1` —
  без визуального эффекта в покое, что и наблюдается (`rest.picked.stroke =
  ["rgb(255, 193, 77)", 1]`).

Побочный эффект, который автор сам назвал в отчёте и я подтвердил чтением:
у `.room.overlay:hover`/`.room.yard:hover` (наведение на незакрашенную
комнату) теперь обе половины (`stroke` и `stroke-opacity`) идут от 0 к 1
вместо одной — начало затухания визуально чуть мягче, монотонность
сохраняется, перелёта нет. Не находка: раскрыто в отчёте автора, не меняет
контракт, не заявлено как AC.

### Проверка «одно число — один источник»

Числа 0.14 / 0.06 / 0.55 / 0.25 (видимые альфы `yard`/`outlined`/`picked`)
встречаются только в `src/styles/plan.styles.ts` — их единственный источник.
Поиском (`grep` по RGB-триплетам `75,140,90` / `62,166,255` / `255,193,77`

компонент (устройство), другое число (0.22), не дублирует величину задачи.
`demo/smoke_merge_highlight.mjs` сверяет только подстроку цвета
(`includes('255, 193, 77')`), а не альфу — совместимость с переходом на
`rgb(...)` + отдельный `fill-opacity` подтверждена прогоном CI (шард 1:
смок зелёный).
