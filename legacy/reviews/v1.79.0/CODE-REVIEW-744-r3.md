### Дельта r2 → r3 — коммит `0f16312e`

```
perf(bundle): load the space-card GUI editor lazily to keep #744 under the initial View budget (#744)
src/space-card.ts | 6 ++++--
```

`src/space-card.ts` статически импортировал свой Lovelace GUI config-редактор
(`./space-editor`, элемент `houseplan-space-card-editor`) — каждый View-фрейм
платил за форму, которую открывает только редактор дашборда. Правка убирает
`import './space-editor'` и делает `getConfigElement()` асинхронным:

```ts
public static async getConfigElement() {
  await import('./space-editor');
  return document.createElement('houseplan-space-card-editor');
}
```

Это буквально тот же контракт, что уже использует `houseplan-card.getConfigElement()`
(`src/houseplan-card.ts:3060`, без обёртки-лоадера — Lovelace сам ждёт промис).
Трейлеры коммита: `Issue: #744`, `User-Visible: no` — верно: это внутренний
механизм загрузки конфигуратора карточки на дашборде, а не видимое поведение
Plan/Devices/View (`docs/SCOPE.md`: редакторы — admin-only поверхность).

## Что проверено и корректно

- Единственная содержательная правка раунда (`0f16312e`, `src/space-card.ts`)
  решает именно то, что заявлено: initial View гейт — красный повод, лазаньый
  вынос `space-editor` — стандартный, уже проверенный в проде паттерн
  (идентичен `houseplan-card.getConfigElement()`).
- Структурная корректность подтверждена манифестом (`space-editor-*.js` как
  отдельный чанк с ожидаемым размером и графом зависимостей) и поведенчески —
  прямым исполнением (зонд в этом раунде): элемент не определён до интента,
  чанк грузится ровно один раз, резолвится форма, которая реально рендерится.
  Это закрывает отсутствие committed-теста для этого пути фактическим
  прогоном, а не доверием к комментарию автора («разовая проверка Playwright»).
- Трейлеры коммита верны (`Issue: #744`, `User-Visible: no` — изменение не
  видимо в Plan/Devices/View, только в конфигураторе карточки на дашборде).
- Бюджет: initial View 301 097 → 300 489 Б gzip (−608 Б), запас до стены
  577 Б; это число видно один раз — в сообщении коммита — источник один
  (`scripts/bundle-budget.mjs` при сборке), UI его не отображает, второго
  источника для сверки «одно число — один источник» нет.
- AC1–AC5 К1–К5 ТЗ #744 (унаследовано из r1/r2, частично перепроверено
  исполнением в этом раунде — см. выше) остаются выполненными; код, который их
  реализует, не менялся в этом раунде.
- `mutation-gate --check` зелёный (exit 0), оба мутанта задачи на месте и
  привязаны к существующему смоку.
