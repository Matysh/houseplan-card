## Что проверено и корректно

- AC1–AC3 остаются доказанными выводами r1 (см. раздел «Унаследовано»
  ниже) — дельта их не касается.
- `docs/TESTING.md`, раздел «Локальный набор перед пушем»: текст теперь
  внутренне непротиворечив — «мутантов нет» (строка ~267), пример команд без
  `--no-mutants`/`--max-mutants` (~276–277), «Что прогоняется» без мутантов и
  с явным пояснением про no-op флаги (~280–283).
- Попутная правка той же задачи (не требовалась Medium из r1, но в тему):
  строки 67–68 сменили формулировку с «Локально для дельты задачи —
  `mutation-gate --changed`» на «Для разбора ночного сбоя (не гейт задачи,
  #709) — …» — устраняет ещё одно потенциальное место, где читатель мог
  принять `--changed` за обязательный локальный гейт. Корректно и не выходит
  за рамки AC2 (тот же файл, та же тема — согласованность канона).
- Код `scripts/pre-push-gate.mjs` не менялся в этой дельте (сравнение
  `git diff a8321e32..HEAD -- scripts/pre-push-gate.mjs` — пусто), значит
  поведение, которое описывает новый текст, — то самое поведение, которое
  проверил r1 (секция мутантов убрана из `manualGate`, флаги не влияют ни на
  что). Документация просто наконец описывает код верно.
- Трейлеры коммита `09d35c8d`: `Issue: #709`, `User-Visible: no` — верно,
  документ не меняет наблюдаемое поведение продукта, changelog не тронут и
  не должен быть тронут.
- Ни одного числа/значения, видимого пользователю, дельта не вводит — это
  README/тестовая документация процесса, не UI и не API.
