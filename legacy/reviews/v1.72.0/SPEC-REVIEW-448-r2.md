  готового перейти в `S5-ready`.

## Чего не проверял

  release-артефакты) — они унаследованы из r1 по таблице выше, дельта их не
  задевает.

- Не проверял golden/smoke/performance фикстуры буквально — на этой стадии их

- Не оценивал техническую реализуемость внутреннего резолвера построчно — не
