## Скоуп ревью

Это возврат по находкам M1/M2 предыдущего раунда, не новый заход задачи. Дельта
локальна: `git diff abfaae3..HEAD` (= коммит `81f3868`) трогает ровно три файла —
`test/wall-thickness.test.mjs`, `scripts/mutation-gate.mjs` и сам документ r1-ревью.
Продуктовый код (`src/wall-thickness.ts`, `src/houseplan-card.ts`) не тронут —
это подтверждено не только диффом, но и байт-в-байт совпадением бандла (см.
«Как проверялось», п.2). Никаких признаков «ребейз на ушедший вперёд dev»,
смены контракта поведения или новой подсистемы нет — `origin/dev...HEAD`
идентичен тому, что видел r1, плюс этот один коммит. Поэтому разбор сокращён
до дельты и наследования, а не полного прогона AC1–AC9.

подтверждённое в r1, не могло сломаться этой правкой.

## Как проверялось

1. Построчно сверен диф `81f3868` с рецептами правок из документа r1 (см.
   таблицу выше) — обе правки текстуально соответствуют тому, что r1 просил
   исправить, а не что-то похожее.
2. Проверено, что продуктовый код не менялся: `git diff abfaae3..HEAD -- src/`
   пуст; после `npm run build` все три копии бандла дают тот же md5, что
   заявляли и автор, и r1-ревью — `5ffd65073d92c4845aecb1a4145f0948`
   (`dist/houseplan-card.js`, `demo/srv/assets/houseplan-card.js`,
   `custom_components/houseplan/frontend/houseplan-card.js`). Это делает
   независимую повторную проверку поведения продукта (AC1–AC9) избыточной —
   она физически не могла измениться.
3. Гейты прогнаны заново на дереве `81f3868` (не унаследованы из r1, так как
   код тестов/гейта изменился):
   - `npx tsc --noEmit` — чисто;
   - `npx tsc -p tsconfig.test.json` — чисто (это конфиг, которым фактически
     компилируются тесты и мутационный гейд);
   - `npm test` — **1026/1026**, включая переписанный тест M1;
   - `node scripts/mutation-gate.mjs --check` — **88/88 `ok`**, exit 0
     (было 87 на r1, теперь на один больше — учтён новый мутант M2);
   - адресный прогон всех четырёх мутантов задачи по одному, чтобы не
     доверять агрегату:
     - `--id=inner-span-ignores-neighbour-thickness` → поймано 1 из 1 (новый, M2);
     - `--id=inner-span-reads-whole-edge-thickness` → поймано 1 из 1
       (переписанный тест M1 всё ещё ловит его, но теперь по правильной
       причине — падает конкретно на сплит-ребре, а не потому что путь через
       профиль не исполнился);
     - `--id=inner-span-shortens-a-passage` → поймано 1 из 1;
     - `--id=resize-labels-show-centreline` → поймано 1 из 1.
4. Прочитан патч M2 в контексте реального `src/wall-thickness.ts:898`
   (`cutAt`, внутри `innerEdgeSpan`) — строка `find` мутанта текстуально
   совпадает с текущим кодом, мутация подставляет собственную толщину `own`
   вместо толщины соседнего ребра `offsets[edge]`, что и есть штраф AC2
   («сокращение считается только по своей толщине, соседи игнорируются»).
   Патч не «на что-то похожее», а именно на тот код, который правка защищает.
5. Проверено, что дифф `81f3868` не трогает `docs/CHANGELOG*.md` и
   `docs/USER-GUIDE*.md` — ожидаемо, коммит несёт `Issue: #233`,
   `User-Visible: no` (тестовый коммит класса B), changelog не требуется.
