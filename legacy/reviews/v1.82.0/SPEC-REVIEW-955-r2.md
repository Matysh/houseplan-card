  влияния на модель настроек и View).

## Чего не проверял

  (сценарий, 9 пунктов скоупа, AC1–AC4 текстуально, файлы/план тестов,
  не-скоуп) — не требуется по §2.10, так как делта локальна и автор прямо
  заявил неизменность AC; содержание унаследовано из r1 (раздел выше).
- Гейты `npx tsc --noEmit`, `npm test`, `npm run build` — не прогонялись:
  этап spec, продуктового диффа нет, зависимости/Chromium не установлены
  (#696); неприменимы.
- Смоки/golden/инварианты модели/pytest — не прогонялись: нет кода для
  исполнения на этом этапе.
- Содержимое мокапов `docs/design/settings-dialogs-944/*.html` построчно по
  каждому из девяти пунктов — не пересматривалось повторно в r2 (разобрано в
  r1 на тех же файлах, которые не менялись).
- Формальная построчная проверка трейлера "Трек: ask — решение владельца" —
  как и в r1, трек и его обоснование зафиксированы в собственном комментарии
