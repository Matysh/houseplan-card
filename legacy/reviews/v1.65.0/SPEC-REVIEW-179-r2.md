   §12) и целиком `docs/reviews/SPEC-REVIEW-179-r1.md`.
2. Прочитано тело issue #179 и все комментарии (`gh issue view 179 --json
   body,comments`), включая ответ автора от `2026-08-19T19:06:37Z` с перечнем
   исправлений.
3. Получен точный diff редакции: `git diff 517a710 2310e6d -- docs/specs/
   179-device-icons-redesign.md` — правка сверялась по факту изменённых строк,
   а не по пересказу автора в комментарии.
4. **Архив дизайнера передекачан и распакован** (`sha256sum` совпал:
   `63670C73E25D1E59DDAF1BE236F3D7F2FAC827B9B5D6DD4B77125EA9BC012025`), чтобы
   независимо перепроверить факты, на которых основана правка:
   - `grep -o feColorMatrix… "Light/Icon Default.svg"` → значения
     `0.145098/0.156863/0.176471` = `37/255, 40/255, 45/255` — подтверждает
     цвет тени из M1;

     единственное отличие — слой `foreignObject` с
     `backdrop-filter:blur(20px)` и атрибут `data-figma-bg-blur-radius`; core/
     stroke/filter-тень (`filter0_ddi_104_1541`) идентичны — подтверждает
     заявление M4/риска о сохранении геометрии;
   - `diff "Light/Icon Default.svg" "Light/Icon Default No Blur.svg"` → файлы
     побайтно идентичны, что согласуется с правилом «Light не содержит blur» и
     с пометкой `deprecated: true, aliasOf: "Light/Icon Default.svg"` для
     Light-варианта в `manifest.json` (у Dark-варианта такой пометки нет —
     перепроверено `grep -n -i "no blur" manifest.json` и чтением окружающего
     JSON, узел `qaFallback`);
   - `grep -in "presence\|green" SPECIFICATION.md ACTIVE_ANIMATION_SPEC.md
     DEVELOPER_HANDOFF.md` — подтверждает, что явного reason→color маппинга в
     архиве по-прежнему нет (это ожидаемо: M2 требовал не найти маппинг в
     архиве, а явно принять и промаркировать решение в ТЗ).
5. Сверена цитата `docs/TOUCH-SUPPORT.md` — таблица контракта содержит ровно
   `| Device editor | … | Best effort |` — правка M5 воспроизводит источник
   точно, без искажения формулировки.
6. Проверена трассируемость: `docs/specs/README.md` не расходится с ТЗ,

  правок вне перечня r1 нет (`git diff 517a710 2310e6d` просмотрен целиком).

  `§10.1` и `§10.4` используют один и тот же mapping `presence/running-working-

- `AC8` и `AC13` обновлены синхронно с текстом §10 и §7.1/§17 — доказательство
  (`pure resolver tests + DOM/style smoke` для AC8, `code assertion +

  добавления новых пунктов.

  затронула); статус документа обновлён («ревизия 2 после жёлтого ревью r1»).
- Трейлеры коммита `2310e6d` (`Issue: #179`, `User-Visible: no`) корректны;
  правка не меняет продуктовое поведение, только сам ТЗ-документ (класс C).
- Открытых продуктовых вопросов владельцу по-прежнему нет; все 7 находок были
