# CODE-REVIEW-618-r2

Issue: #618 — «Редактор устройств: массовые операции над скрытыми маркерами и
«показать всё скрытое»». Материал: `93bacc96961b7a1b8230fd7f43aa71fe2aa08a5d`
(рабочая копия). Заход **r2**, блокирующих циклов израсходовано 0 из 4.

Причина захода: код-ревью r1 (`docs/reviews/CODE-REVIEW-618-r1.md`) было
**зелёным**, но слияние отказало — ветка отстала от `origin/dev` на 32
коммита (#642, #627, #617 и инфраструктура). Автор переиграл ветку на
`origin/dev` `2b3959e5` и запушил `93bacc96`; продуктовое поведение по
заявлению автора не менялось. Это ребейз на ушедший вперёд `dev` —
по правилу §2.10 разбор в таком случае остаётся полным, но с опорой на то,
что уже доказано в r1 там, где дельта не коснулась контракта.
