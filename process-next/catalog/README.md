Числа деклараций — статический AST Node / определения Python, не исполненные кейсы. Параметризация, циклы, вложенные тесты и пропуски меняют результат. 92 адресных файла не означают обязательные 721 проверки: механизмы разнесены по упаковке, harness, визуальным инструментам, измерениям, ревью и fixtures; смешанные части требуют отдельного решения при переносе.

Оставшиеся 490 browser-файлов — консервативный инвентарь stable, **не утверждение о выполненной содержательной ревизии каждого кейса**. Бета использует ровно 13 файлов. У Node 10 групп и import/data closure; динамические читатели исходного дерева консервативны. Browser запускает всю карточку и имеет широкие зависимости: узкое повторение одного browser-кейса по любому src-изменению не заявлено.

Golden runner адаптирован из старого с сохранением semantic/pixel assertions. При активации две копии нужно объединить. Все 23 PNG беты существуют. Четыре оставшиеся static-wall-opening сцены пока без PNG: они не принимаются автоматически и не объявлены прошедшими.

Шесть Python converter-контрактов используют реальные schema/import/preview продукта с внешними golden fixtures; обычная защита импорта/повреждённых документов сохранена. Coverage знаменатель не сужен; влияние исключения этих файлов на порог 87.2% здесь не измерялось. Отсутствующий полный converter E2E #1179 явно unavailable и диагностический.

Собственные тесты каталога — 7 исполняемых сценариев, без запуска продуктовых наборов. Это проверка изменённого механизма, не новый этап каждой задачи.
