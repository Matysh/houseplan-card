# Инвентарь миграции #1105

Исполняемые профили — в ../lib/catalog.mjs; решения процесса — в ../decisions/1105.json. Здесь нет второго процесса или обязательного запуска аудита. Оригинальные тесты и действующие workflow не изменены.

inventory.json перечисляет 591 Node-файл, 108 backend-файлов, 492 browser-файла и 326 golden-сцен коммита 96a97b8. Это исходный снимок аудита; его golden `beta`/`baselinePresent` описывают прежнюю выборку. Актуальное размещение и состав визуальных сцен определяют selections.mjs и golden-selection.mjs. Решения: retire — кандидат на удаление при переключении; addressed — только при изменении механизма; keep — оставлен в соответствующей продуктовой выборке.

Числа деклараций — статический AST Node / определения Python, не исполненные кейсы. Параметризация, циклы, вложенные тесты и пропуски меняют результат. 92 адресных файла не означают обязательные 721 проверки: механизмы разнесены по упаковке, harness, визуальным инструментам, измерениям, ревью и fixtures; смешанные части требуют отдельного решения при переносе.

Оставшиеся 490 browser-файлов — консервативный инвентарь stable, **не утверждение о выполненной содержательной ревизии каждого кейса**. Бета использует ровно 13 файлов. У Node 10 групп и import/data closure; динамические читатели исходного дерева консервативны. Browser запускает всю карточку и имеет широкие зависимости: узкое повторение одного browser-кейса по любому src-изменению не заявлено.

Golden runner адаптирован из старого с сохранением semantic/pixel assertions. При активации две копии нужно объединить. Конкретизация поручения владельца от 01.11: **22 кадра панели + 3 Lovelace = 25**. Вместо двух общих геометрических View используются существующие compact/three-rows панели (тот же дом); светлый широкий View сохранён. Все специализированные темы прежней выборки сохранены.

Пять панельных и три карточных ID уже имеют PNG. Для 17 новых панельных ID **эталонов пока нет**; старые PNG карточки не переиспользуются и не принимаются автоматически. Stable использует ту же выборку плюс остаток: 17 новых вариантов заменяют исходные, поэтому общий подготовленный состав остаётся 326 сцен (25 + 301), без двойной матрицы. Четыре существующие Static-сцены в остатке также пока без PNG. Действующая `demo/golden/matrix.mjs` и её эталоны не изменены.

Проверка подготовки в WSL: все 25 кадров сняты за 25,0 с, ошибок подготовки/смысловых проверок нет; 2 совпали, 6 отличаются от прежних эталонов, для 17 ожидаемо нет новых эталонов. Это **не зелёный визуальный набор**. Отчёт: `../evidence/golden-panel-beta-wsl.json`. Унификация самой шапки — отдельная продуктовая #1184.

Coverage знаменатель не сужен; влияние исключения этих файлов на порог 87.2% здесь не измерялось. Отсутствующий полный converter E2E #1179 явно unavailable и диагностический.
