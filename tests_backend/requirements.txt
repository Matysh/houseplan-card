# Зависимости HA-харнесса, закреплённые точно (issue #392).
#
# Было так: `pip install pytest voluptuous pytest-homeassistant-custom-component
# home-assistant-frontend` без единой версии. Резолвер молча выбирал набор сам,
# и выбор зависел не от нашего коммита, а от того, что в этот день лежит на
# PyPI. По SHA нельзя было сказать, чем его проверяли.
#
# Что здесь записано — ровно то, что резолвилось на 30.08.2026, снятое из лога
# шага `pip install`. Цель этого файла не «взять новое», а «перестать дрейфовать».
#
# Знать про эти версии нужно две вещи.
#
# 1. `pytest-homeassistant-custom-component` начиная с 0.13.348 (25.07.2026)
#    требует Python >= 3.14, а job стоит на 3.13. Поэтому резолвер и уезжал на
#    0.13.316 — последнюю, которая ставится на 3.13.
# 2. Она тянет `homeassistant==2026.2.3`, то есть февральский. Харнесс проверяет
#    интеграцию против HA, которого у пользователей давно нет. Это известный
#    долг, а не оплошность: снимать его надо переходом на 3.14 и свежий phcc,
#    и это отдельная задача с отдельным измерением.
#
# Менять версии здесь можно, но только вместе с прогоном полного набора: это
# не косметика, а смена того, что означает зелёный backend.
pytest==9.0.0
voluptuous==0.15.2
pytest-homeassistant-custom-component==0.13.316
home-assistant-frontend==20260128.6
# Ставится транзитивно из phcc; закреплён явно, чтобы версия была видна тому,
# кто читает этот файл, а не только тому, кто читает лог.
homeassistant==2026.2.3
