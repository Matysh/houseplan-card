## Запуск на другом ПК

Скачайте этот каталог целиком. В отдельном checkout House Plan указанного коммита:

```sh
npm ci --ignore-scripts
npm run build
npm run ui-lab:prepare
node /path/to/materials/serve.mjs --repo /path/to/houseplan --port 8890
```

Для уже подготовленного HA runtime добавьте `--ha-cache /path/to/cache`.
Сборка берётся из `dist`, исходники продукта и tracked frontend не меняются.
Сервер доступен только на loopback: http://localhost:8890/.
Точная версия продукта и fingerprint доступны в `/health`.

## Использование

Открывается отдельное пространство «#1129 · Матрица устройств». Код 07F на плане
совпадает с 07F в MATRIX.md. В нижней панели можно выбрать строку, показать всю
сетку, повторить короткое событие, остановить автоповтор, переключить тему,
live states, уменьшение движения или настоящий редактор. Зум/таскание плана
остаются штатными. Для 2.5D используется обычная настройка продукта.

«Фиксация UI» показывает hover/фокус/выделение одновременно в соответствующих
строках. Лаборатория копирует декларации загруженного продуктового CSS, меняя
только селекторы для этих строк. Это внешний вид состояний, а не несколько
одновременных нативных фокусов. Отключите фиксацию для проверки мышью/клавиатурой.
«Меньше движения» вызывает продуктовый обработчик и применяет его CSS-правила;
не меняет настройки операционной системы.

Автоповтор создаёт реальные переходы синтетических сущностей каждые 6 секунд.
Внимание проявляется после штатной задержки подтверждения 3 секунды.
Группы собираются штатным геометрическим движком после измерения подписей.

## Материалы

- `MATRIX.md` — таблица и расшифровка состояний.
- `generate.mjs` — единое описание строк/столбцов; из корня checkout запускается
  `node /path/to/materials/generate.mjs` и создаёт fixture, matrix и Markdown.
- `fixture.json` — готовые синтетические данные.
- `matrix.json` — коды, координаты, источники и группы.
- `serve.mjs`, `matrix.mjs` — локальная оболочка и управление стендом.
- `inspect.mjs`, `report.json`, PNG — адресная проверка и снимки реального продукта.
  Проверка запускается из корня checkout: `node /path/to/materials/inspect.mjs http://localhost:8890/`.
  Нужен Chromium Playwright. Используется отдельный браузерный контекст.

Проверка диагностическая: не является приёмкой исправления #1129, изменением
визуальных эталонов или полным продуктовым прогоном тестов.
