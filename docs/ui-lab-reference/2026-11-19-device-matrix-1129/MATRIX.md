### Что задаёт каждая строка

- **01. Выключено / покой:** Доступно; обычная иконка, без пульса.
- **02. Работает:** Постоянная работа: янтарная пульсация в режиме «Активность».
- **03. Короткое событие:** Датчик движения: реальный фронт off→on каждые 6 секунд, короткий эффект 3,3 с.
- **04. Присутствие:** Непрерывный presence, зелёная пульсация.
- **05. Переход:** Cover opening: непрерывный переход. Защищённая пиктограмма cover.
- **06. Завершение перехода:** Cover closed↔open: короткий конечный переход каждые 6 секунд.
- **07. Тревога:** Нативный smoke: красная тревога во всех динамических режимах, включая значение.
- **08. Обслуживание:** Home Connect Machine Care: отдельный ключ, без красной тревоги.
- **09. Внимание:** Свой порог, attention после штатного подтверждения 3 с.
- **10. Внимание + обслуживание:** Два раздельных служебных значка.
- **11. Тревога + внимание + сервис:** Тревога имеет приоритет: служебные значки подавляются; причины остаются.
- **12. Unavailable:** Все собственные сущности unavailable: одно приглушение всего значка.
- **13. Unknown:** Неизвестные данные не означают подтверждённый offline.
- **14. Источник значения unavailable:** Само устройство доступно; недоступно только выбранное значение.
- **15. Источник бейджа unavailable:** Само устройство доступно; недоступно только содержимое бейджа.
- **16. Источники удалены:** Настроенные value/badge ссылаются на отсутствующую сущность: штатный fallback.
- **17. Новое устройство:** Красная отметка нового устройства.
- **18. Скрытое + новое:** Серая отметка скрытия при включённом «глазе», приоритет над новым.
- **19. Выключено в HA:** В текущем dev полностью скрывается даже при включённом «глазе»; в ячейке явно подписано отсутствие маркера. Активность запрещена.
- **20. Привязка потеряна:** Устройство удалено из реестра; диагностическое представление.
- **21. Виртуальное:** Виртуальная привязка, пунктирный контур; нет собственного offline. В текущем dev собственное значение уступает иконке (fallback), внешний бейдж сохраняется.
- **22. Hover:** Зафиксированный штатный hover для сравнения всей строки.
- **23. Hover + тревога:** Тревога остаётся красной поверх hover.
- **24. Hover + offline:** Offline не подменяется активным hover.
- **25. Выделено в редакторе:** Зафиксированный стиль штатного выделения. Кнопка «Редактор» проверяет живое поведение.
- **26. Клавиатурный фокус:** Зафиксированный штатный :focus-visible. Живой фокус также проверяется Tab.
- **27. Заряд 80% · LQI 212:** Зелёный полный заряд и хороший сигнал.
- **28. Заряд 25% · LQI 100:** Промежуточный заряд и сигнал.
- **29. Заряд 5% · LQI 30:** Низкий заряд и плохой сигнал.
- **30. Заряд unknown · нет LQI:** Неизвестный заряд; отсутствующий LQI не выдумывается.
- **31. Замок закрыт:** Нативное состояние locked; безопасные действия сохраняются.
- **32. Замок открыт:** Нативное состояние unlocked; защищённая пиктограмма.
- **33. Cover закрыт:** Защищённая динамическая пиктограмма закрытого cover.
- **34. Cover открыт:** Защищённая динамическая пиктограмма открытого cover.
- **35. Бейдж слева:** Слева; для колонок без бейджа — контрольная форма.
- **36. Бейдж сверху:** Сверху; длинные значения не должны срезать эффект.
- **37. Бейдж снизу + LQI:** Снизу; LQI уходит под бейдж, не перекрывает его.
- **38. Статическое оформление:** static_icon / value_static_icon: нативная тревога не перекрашивает статическую лицевую сторону; дополнительные бейджи штатно скрыты.
- **39. Без обычной активности:** Режим «Иконка» / «Значение»: работа без обычных волн.
- **40. Свой цвет и размер:** Работа; фиолетовый цвет, диаметр 2,2. Тревога по-прежнему имеет свой красный эффект.
- **41. Поворот иконки 45°:** Индивидуальный угол; бейдж и его текст сохраняют штатное положение.
- **42. Размер 75% / 140%:** Чередование размеров; группа содержит неодинаковые тела.

### Оси проверки, общие для всей сетки

- Светлая / тёмная тема, обычный View / 2.5D, системное уменьшение движения, включение/выключение live states. Это отдельные режимы всей матрицы: их не смешиваем с ложными per-device настройками. При reduced motion обычная активность становится точкой, тревога остаётся красной без анимированных колец.
- Hover / focus / выделение в строках 22–26 закреплены только лабораторией, используя декларации штатных стилей. Это показывает внешний вид одновременно в нескольких ячейках; настоящий hover, Tab и редактор устройств остаются доступны для проверки взаимодействия.
- Все пять display modes, четыре позиции бейджа (right по умолчанию, left/top/bottom отдельными строками), разные размеры, угол, короткие и длинные значения, собственный цвет/диаметр волн.
- Доступность самого устройства независима от отсутствующего/недоступного value/badge. Off, unknown и unavailable не смешиваются.
- Нативная тревога, пользовательское внимание, обслуживание и приоритет тревоги; четыре класса пульса (none/alarm/short/continuous) и причины event/presence/transition/running.
- Новое/скрытое/HA-disabled/осиротевшее/виртуальное, четыре состояния батареи и диапазоны LQI. Недопустимые состояния (например, работа HA-disabled) не подделываются.

Это конечный каталог визуальных ветвей и существенных сочетаний, а не бесконечный перебор всех текстов, чисел, цветов и декартова произведения независимых настроек. Показания подобраны так, чтобы обнаружить ошибки геометрии. Пылесос в движении, линии LED, радарные цели и символы проёмов — отдельные изображения плана, не варианты корпуса этой иконки; в #1129 их не подменяем обычным значком.

Полная синтетическая fixture и machine-readable matrix.json генерируются из одного описания; имена/код ячейки доступны в штатной подсказке устройства. Лабораторные действия не вызывают настоящий HA.
