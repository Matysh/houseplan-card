# #1495 / UI-062 — согласованный визуальный прототип

20.11.2026 владелец принял текущий вид, включая **непрозрачную белую подложку стен вместо прозрачности в 2.5D**. Каноническое описание — [JOURNAL.md](JOURNAL.md), задача — [#1495](https://github.com/Matysh/houseplan-card/issues/1495).

## Содержимое

- `prototype.patch`: все четыре изменённых/добавленных исходника относительно опубликованного тега.
- `lab/`: синтетический обычный план Ground floor / 2nd floor и пространство «Диагональные стены», исходные цвета, лабораторные контролы и сервер.
- `screenshots/white-backing-1.png`, `white-backing-0.4.png`, `white-backing-0.png`: финальная версия; числа обозначают непрозрачность окраски 100%, 40%, 0%, белое основание остаётся непрозрачным.
- Остальные кадры: согласованная тональная поправка до добавления белого основания, на непрозрачных стенах (этот вид не изменялся). `white-before.png` — исходное плоское освещение для сравнения.
- `manifest.json`, `SHA256SUMS`: точная база и состав пакета.

## Воспроизведение на другом ПК

1. Получить этот каталог из указанной ветки/коммита. Подготовить отдельный checkout `v1.86.0-beta.2` (`6af2e11c1e83442c2dbfd7bbfa2a888466fbbcc1`).
2. Применить `git apply <абсолютный путь к prototype.patch>` в checkout. Установить зависимости `npm ci`, собрать `npm run build`.
3. Подготовить штатный HA frontend для UI Lab командой `npm run ui-lab:prepare` из checkout (или использовать совместимый локальный cache). Это загрузка frontend-ресурсов, подключение к настоящей HA-инсталляции не требуется.
4. Из checkout запустить `node <путь к пакету>/lab/serve.mjs --repo <путь к checkout> --port 8890`. При внешнем cache добавить `--ha-cache <путь к cache>`. Открыть `http://localhost:8890/`.

Пути к исходникам/кешу на исходном ПК не нужны. Сервер использует файлы из своего каталога и принимает только loopback GET/HEAD. Пакет не содержит bundle, node_modules, частные assets, токены или localStorage.

Сохранить совместимость данных и Flat. Обязательно отдельно проверить совпадение тонов кладки под окнами/над проёмами, реальную видимость рёбер, 0/частичную/полную непрозрачность окраски, сохранность проходов/стекла, а также плавность и единый вид растрового и точного SVG при жестах на крупной сцене. Утверждение дизайна не заменяет приёмку реализации и не разрешает автоматически обновить golden-файлы.
