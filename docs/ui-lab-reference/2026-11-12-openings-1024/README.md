## Воспроизведение на другом ПК

Скачайте этот каталог целиком. Используйте отдельный чистый checkout продукта на указанном commit, чтобы не затронуть текущую работу. Пусть `REFERENCE` обозначает абсолютный путь к скачанному каталогу. Из корня такого checkout:

```sh
git apply <REFERENCE>/runtime-prototypes.patch
```

Скопируйте `accepted/lab-native-opening.ts` в `src/lab-native-opening.ts`. Затем:

```sh
npm ci --ignore-scripts
npm run build
npm run ui-lab:prepare
node <REFERENCE>/serve-reference.mjs --repo <CHECKOUT> --port 8892
```

При уже подготовленном HA frontend пропустите подготовку и передайте `--ha-cache <CACHE>`. Требуется Node.js 22. Сервер слушает только 127.0.0.1, на http://localhost:8892/ открывается штатный UI Lab со стандартными синтетическими данными. В редакторе плана можно нарисовать цепочку, выбрать стену, передвинуть узел или воспользоваться Resize. Данных/файлов владельца и подключения к его HA не требуется.

`serve-reference.mjs` — переносимый загрузчик для сохранённого слоя, не байтовая копия частного сервера. Он не переносит старую браузерную сессию. Снимки кода точные; воспроизведение пакета на другом ПК в момент фиксации отдельно не прогонялось. Фактические проверки сделанного прототипа перечислены в журнале. SHA-256 файлов — в `MANIFEST.json`.

# Просмотр принятого варианта

1. В штатном синтетическом плане открыть редактор плана, выбрать окно и его свойства. Обычное окно имеет две створки; плюс/минус дают 1–4, одна строка открывает настройки створки.
2. У окна изменить общее открывание; у створок проверить боковые петли и «Открывается вверх», ручное положение и состояние с назначенным синтетическим датчиком. Превью следует ориентации плана.
3. Включить шторы/жалюзи/ставни: ручное положение или синтетическая сущность, соответствующая иконка на противоположной стороне окна.
4. Сохранить окно, посмотреть смешанные открытые створки, ручки/дуги/направляющие, 20%-стекло и блики. Финальное верхнее полотно сужено на 3 см с каждой стороны, без зазоров между створками.
5. В свойствах двери/ворот проверить ручное открыто/закрыто без контакта, disabled-поле с контактом, распашной/откатной механизм.

Данные сохраняются только локально в этом синтетическом Lab. Backend-миграция, полный Sun/Glow, экспорт и совместимость должны быть реализованы/проверены отдельно по SPEC.md. Ключ houseplan-ui-lab:native-openings:1024:v1 относится только к прототипу, не к продукту.

SPEC-before-UI059.md — архив прежнего ТЗ для истории ревью, не второй источник требований. Текущая редакция SPEC.md и тело issue имеют приоритет. Материалы не содержат частных планов, реестров, сессий и кадров владельца.
