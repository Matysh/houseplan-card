# Адресные сценарии

Запускать из корня восстановленного checkout; `HP_REPO` при необходимости задаёт его путь, `HP_LAB_URL` — адрес отдельного UI Lab (по умолчанию localhost:8891). Playwright берётся из зависимостей checkout. Сценарии работают в собственном браузерном контексте. Кадры этих проверок пишутся рядом со скриптом. Это вспомогательные smoke из итерации, не новая обязательная CI-матрица.
