# Переносимый эталон 2.5D — UI-060

Согласован владельцем 19.11.2026. Это пакет переноса визуального прототипа в продукт, не готовый продуктовый релиз.

## Что внутри

- `REQUIREMENTS.md` — все итоговые решения и AC, включая визуальное совпадение.
- `JOURNAL.md` — принятая запись цикла.
- `product-prototype.patch` — все изменения `src/` относительно исходной беты, включая новые файлы.
- `lab-support.patch` — отдельно изменения `demo/ui-lab/` для IndexedDB. Не применять их к backend продукта.
- `source-files.json`, `build-manifest.json`, `SHA256SUMS` — идентичность исходников, принятой сборки и файлов пакета.
- `synthetic-fixture.json` — только синтетические данные; не копия дома владельца.
- `capture.mjs`, `checks/`, `evidence/` — воспроизводимые кадры и адресные диагностические сценарии.
- `lab-support/session-continuity.mjs` — дополнительное сохранение совместимой локальной сессии между сборками; новому чистому стенду не требуется.

## Воспроизведение на другом ПК

Нужны Git, Node.js 22, Python для штатной подготовки HA frontend, Chromium для снимков. Частный localhost владельца и его Windows-диски не нужны.

1. Скачать эту reference-ветку репозитория. Её продуктовые исходники соответствуют исходной бете `163fc4a94159e91516c21c6b520ccfc5455a32f0`; изменения хранятся в patch-файлах.
2. В отдельном рабочем checkout reference-ветки выполнить из корня репозитория:

```sh
git apply docs/ui-lab-reference/2026-11-19-2_5d/product-prototype.patch
git apply docs/ui-lab-reference/2026-11-19-2_5d/lab-support.patch
npm ci --ignore-scripts
npm run build
npm run ui-lab:prepare
node demo/ui-lab/server.mjs --port 8891 --fixture docs/ui-lab-reference/2026-11-19-2_5d/synthetic-fixture.json
```

Если HA-кэш уже подготовлен, добавить `--ha-cache /path/to/cache`. Зафиксированная версия frontend и проверка целостности — в штатном `demo/ui-lab/ha-lock.json`. Сборка идёт в `dist`; `custom_components/houseplan/frontend` не требуется переписывать.

3. Открыть `http://localhost:8891/`. Все действия остаются в локальном mock, настоящий HA не используется. Для снимков:

```sh
node docs/ui-lab-reference/2026-11-19-2_5d/capture.mjs --repo . --url http://localhost:8891/
```

Сценарий загружает приложенную синтетическую сцену в отдельный контекст Chromium; пользовательское хранилище не очищает. Для нескольких экземпляров можно передать `--out /path/to/screenshots`.

## Как читать результаты

Утверждён итоговый живой прототип; приложенные общие кадры сняты с него после утверждения на синтетических данных для передачи. Это не отдельно принятые golden и не доказательство всей продуктовой матрицы.

Исходная база воспроизводится из тега `v1.85.3-beta.2` без patch-файлов. Старые промежуточные снимки с частным планом не опубликованы. Сравнение до/после при реализации должно использовать одинаковую синтетическую сцену и одинаковую камеру.

Проверки, реально выполненные в итерации: сборка с TypeScript; адресная проверка акцента/прозрачности/подоконников и сохранения после reload; проверка общего множителя материала мебели/лестниц. Более ранние проверки высот, масок, ракурсов, теней и света выполнялись в ходе прототипирования, а не полным повтором после каждой правки. Полные S6, HA E2E, golden и измерения производительности текущего набора не проводились. Требования к их объёму задаёт актуальный процесс при переносе.

В `checks/` сценарии сохранены как вспомогательные проверки, не как новая обязательная CI-матрица. Прототип не заменяет поддержку нового поля в серверной модели и backup.
