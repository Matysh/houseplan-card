## Запуск на другом ПК

Нужны Git и Node.js 22 (исходная среда 22.23.2). Отдельные каталоги сохраняют ваши текущие рабочие деревья.

```sh
git clone --branch issue/1376-ui-lab-reference-20261109 https://github.com/Matysh/houseplan-card.git houseplan-mdi-reference
git clone https://github.com/Matysh/houseplan-card.git houseplan-mdi-product
cd houseplan-mdi-product
git checkout --detach 8474326a1425d5cccb37c289d64b4498db6a4c8a
npm ci --ignore-scripts
npm run bundle:sync
npm run ui-lab:prepare
node ../houseplan-mdi-reference/docs/ui-lab-reference/2026-11-09-mdi-picker/serve-reference.mjs --repo . --port 8892
```

Открыть http://localhost:8892/. Кнопка UI LAB → «Устройство», затем в настройках устройства «Отображение на плане» → «Иконка». Выбрать иконку, сохранить, открыть настройки повторно и сбросить крестиком: автоматическая иконка должна показываться сразу. Проверить мышь, Enter, Escape, стрелки, touch и поворот стрелки. Полный набор состояний описан в ACCEPTED.md.

`ui-lab:prepare` — явная загрузка официального закреплённого HA frontend 20260930.4 (около 111 MB); при готовом кэше пропустить. Для своего каталога передайте `--ha-cache <каталог>` подготовке и серверу. Сам сервер ничего не скачивает и не обращается к живому HA. Остановка Ctrl+C.

«До» можно открыть отдельно на той же продуктовой базе:

```sh
npm run ui-lab -- --port 8893
```

Сравнивайте одинаковые данные/состояния в свежих браузерных сессиях. Порты не разделяют localStorage. Для поворота стрелки и мобильной подсветки проверяйте переход, а не только конечный кадр.

Issue закрепляет неизменяемую ссылку на commit материалов. При необходимости checkout reference-клона на этот commit. Сервер требует точный product HEAD, fingerprint и anchors; несовпадение приводит к ошибке. Не исправляйте принятый эталон под свежую сборку.

## Границы переноса

Патчи меняют HTTP-ответы штатного offline UI Lab; сборка на диске и продуктовые исходники не меняются. Fingerprint относится к исходной сборке, не преобразованным байтам. Не переносить подмены минифицированных чанков в продукт: реализовать поведение в компонентах и общих стилях UI Kit актуального dev.

Запуск использует стандартную синтетическую fixture и штатные ограничения loopback. Файлы из `accepted/` с частными локальными именами входов — архив исходного механизма; запускать нужно переносимый `serve-reference.mjs`, ему эти частные файлы не требуются.

Проверки, проведённые во время итерации, перечислены в журнале. Это не полный S6, не проверка всех браузеров и не автоматическое обновление golden. Прежние эталоны не менялись; визуальное покрытие picker требуется сохранить и актуализировать при реализации по процессу.
