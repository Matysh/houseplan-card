## UI-054 — собственный MDI picker

| Область | Согласованное поведение |
| --- | --- |
| Курсор | `pointer` по всей кликабельной площади закрытого поля, включая участок справа от крестика и область стрелки. |
| Очистка | Крестик сразу сбрасывает к **автоматической иконке по текущей привязке/правилам**, а не к предыдущей пользовательской. Совпадают иконка, подпись поля и предпросмотр; сохранение и повторное открытие не меняют уже показанный результат. Проверить также ранее сохранённую пользовательскую иконку, новую несохранённую, смену привязки и виртуальное устройство. |
| Крестик | Круглая область hover 40 × 40 px, `border-radius:50%`, цвет как у закрытия диалогов: `rgb(127 127 127 / 16%)`. Сам крестик точно в центре круга по обеим осям. Использовать симметричный стандартный glyph и центрирование, не компенсировать дефект случайным смещением. |
| Hover поля | Как у остальных `hp-settings-select`: акцентная рамка и подложка UI Kit, общие HA theme tokens и плавность; без самостоятельного варианта оформления. |
| Первый пункт | При раскрытии и после изменения поиска нет автоматически нарисованной рамки вокруг первого результата. Клавиатурная навигация сохраняется: первая ArrowDown выбирает первый результат, ArrowUp — последний; затем обычное перемещение. Enter после поиска по-прежнему может выбрать первый результат. Не формировать `aria-activedescendant` с несуществующим индексом. |
| Единая рамка | После выбора мышью/Enter, очистки, Escape и повторного открытия остаётся одна внешняя рамка поля. Убрать сочетание внешней рамки, inset-shadow и внутреннего outline кнопки. Клавиатурный фокус остаётся различимым через состояние общего поля; не отключать фокус у всех элементов страницы. |
| Подсказка | Полностью убрать «Уточните поиск, чтобы найти нужную иконку» и место под неё. Не оставлять пустую полосу/отступ. Сообщения загрузки, ошибки и действие повторной загрузки сохраняются. Лимит результатов и поиск этим изменением не отменяются. |
| Стрелка | При раскрытии плавно поворачивается на 180°, при закрытии возвращается. Как у аналогичных элементов UI Kit: paint motion 160 мс ease; при reduced motion без анимации. Работает при выборе, Escape, повторном нажатии и закрытии снаружи. |

### Подтверждённые причины

- При открытии настроек `autoIcon` заполнялся из `d.icon`, уже содержащего пользовательское переопределение. Прототип вычисляет авто через `_autoIconForBinding` текущей привязки, как при её изменении.
- Двойная рамка воспроизведена: `.field:focus-within` добавлял inset-shadow к рамке, а после ввода с клавиатуры и возврата фокуса `.trigger:focus-visible` рисовал ещё outline.
- У прежнего SVG крестика визуальный центр был на 1,4 px выше центра кнопки. После замены пути и центрирования измеренное смещение 0/0 px.

## UI-055 — отключение системной подсветки тапа

- В мобильном режиме браузер добавлял прямоугольную голубую подсветку поверх округлого оформления UI Kit. На стенде подтверждено computed значение `rgba(51,181,229,.4)`.
- Для **всех выпадающих контролов общего UI Kit**, их кликабельных триггеров и пунктов списков задать `-webkit-tap-highlight-color: transparent` в общем механизме оформления.
- Обязательно охватить обычные settings select, MDI picker, выбор источников и другие потребители общих floating/menu styles. Учитывать Shadow DOM, popover и fallback-представление; в прототипе общий floating-control стиль также покрывает color picker и его содержимое.
- Отключается только дополнительная браузерная подсветка. Выбранное/активное состояние, hover, клавиатурный фокус, скругления, нажатия и прокрутка UI Kit сохраняются.
- Не дублировать исправление по отдельным диалогам и не запрещать системные жесты или выделение текста глобальным обработчиком.

## Проверено на прототипе

Адресные проверки выполнялись по мере правок, без полного продуктового pipeline:

- Hover поля совпал с соседним settings select по background и border; курсор pointer.
- Пользовательская `mdi:fan` сохранена и настройки открыты заново: автоиконка остаётся `mdi:smoke-detector`; очистка сразу показывает именно её.
- Круг очистки 40 × 40, radius 50%, цвет `rgba(127,127,127,.16)`; центр glyph относительно круга — 0/0 px.
- После выбора мышью, Enter и Escape: внешняя рамка 1 px, shadow none, внутренний outline none.
- При открытии active=-1 и outline первого пункта none; первая ArrowDown активирует индекс 0.
- Chromium с touch/mobile viewport 390 × 844: у обычного select, MDI поля и пунктов обоих списков tap-highlight после правки прозрачный; радиусы сохранены.
- Стрелка: открыто — поворот 180°, закрыто — 0°, переход 0.16 s. Ошибок страницы в адресных прогонах не было.

Это не полная приёмка продукта или всех мобильных браузеров. Проверка WebKit и общего охвата потребителей остаётся частью реализации.
