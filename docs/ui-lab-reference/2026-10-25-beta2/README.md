## Получение и запуск с другого компьютера

Нужны Git и Node.js 22. Используйте отдельную копию репозитория: текущую рабочую ветку исполнителя переключать не нужно.

```sh
git clone --single-branch --branch issue/1081-ui-lab-reference-20261025 https://github.com/Matysh/houseplan-card.git houseplan-ui-reference
cd houseplan-ui-reference
npm ci
node docs/ui-lab-reference/2026-10-25-beta2/verify-package.mjs
npm run ui-lab:prepare
node docs/ui-lab-reference/2026-10-25-beta2/serve-reference.mjs
```

Откройте **http://localhost:8892/**. Для пустой установки и диалога импорта этажей остановите сервер (`Ctrl+C`) и запустите:

```sh
node docs/ui-lab-reference/2026-10-25-beta2/serve-reference.mjs --empty
```

Затем обновите страницу. Две сцены имеют разную идентичность локальной сессии. Сохранённые эксперименты можно сбросить через **UI LAB → сброс локальной сессии**. Пустая сцена содержит два вымышленных этажа, чтобы автоматически открыть диалог импорта; закройте диалог, чтобы увидеть стартовый экран.

`ui-lab:prepare` загружает закреплённый официальный Home Assistant frontend; адрес реального Home Assistant и токен не нужны. Уже подготовленный проверенный кэш можно указать через `--ha-cache /path/to/cache`. Порт задаётся через `--port 8892`. Обычный запуск ничего не скачивает и слушает только loopback.

**Не запускайте `bundle:sync` для этого эталона:** `prepare-reference.mjs` проверяет и копирует в `dist/` готовую опубликованную сборку из закреплённого коммита. При другой сборке или конфликтующем `dist/` запуск завершится ошибкой без перезаписи файлов. `--repo /path/to/pinned-clone` позволяет хранить пакет отдельно от клона.

## Состав и границы эталона

Все 13 файлов `accepted/` и `JOURNAL.md` побайтно совпадают с архивом принятого стенда от 25.10.2026; это проверяется отдельно от целостности транспортных файлов. `accepted/app.mjs` сохранён для происхождения эталона, но не запускается: переносимая версия использует штатный bootstrap из закреплённого репозитория и устанавливает те же адаптеры через `install.mjs`. `reference-theme.css` содержит только CSS оформления.

Частные планы, HA-реестры/состояния владельца, изображения, резервные копии и браузерные сессии **не включены**. Используется публичная синтетическая fixture из `demo/ui-lab/fixture.json`. Старые локальные пути из журнала — исторические ссылки, а не обязательные файлы для запуска этого пакета. В `SOURCE-MANIFEST.json` сохранены имена и хэши исключённых материалов для проверки происхождения; их содержимого здесь нет.

Скриншоты исходного частного стенда не опубликованы. Новые снимки синтетической сцены не следует выдавать за оригинальные одобренные пользователем кадры. Для визуального сравнения запускайте отдельно этот эталон и реализацию **на одинаковых синтетических данных, размере окна, языке и теме**. Не подключайте `accepted/overrides` к проверяемой реализации: это скроет её собственные расхождения. Если конкретный AC требует именно исходных частных снимков, потребуется их отдельная приватная передача; наличие этого пакета не отменяет такой AC автоматически.
