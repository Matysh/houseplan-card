# Согласованный прототип #1608

Высота устройств и LED-лент, разделение обводок по высоте, диапазон в форме, hover контекстного меню и перспектива всех ракурсов. Решения и границы проверки: [JOURNAL.md](JOURNAL.md). Пакет доступен из Git, локальные файлы владельца не требуются.

- `BASELINE.json` — точная база и fingerprint проверенной сборки.
- `prototype.patch` — изменения отслеживаемых исходников относительно базы.
- `added/marker-height.ts` — новый модуль, дополняющий patch.
- `fixture.json` — опубликованный синтетический двухэтажный план с четырьмя дополнительными примерами Авто / 0 / 60 / 133,52 см.
- `serve-reference.mjs` — переносимый загрузчик fixture. Темы и графические ресурсы берутся из `demo/ui-lab/default-plan` закреплённой базы.
- `screenshots/` — согласованный визуальный вид, не продуктовые golden-эталоны.
- `MANIFEST.json` — SHA-256 материалов.

## Воспроизведение на другом компьютере

Сохранить этот каталог как `<REFERENCE>` вне рабочего checkout. В отдельном чистом checkout базы **1a6660aec8bbd8012b4ad26f76982f0fa15d09dd**:

```sh
git apply <REFERENCE>/prototype.patch
# Скопировать <REFERENCE>/added/marker-height.ts в src/marker-height.ts
npm ci --ignore-scripts
npm run build
npm run ui-lab:prepare
node <REFERENCE>/serve-reference.mjs --repo <CHECKOUT> --port 8892
```

При уже подготовленном HA frontend пропустить `ui-lab:prepare` и передать `--ha-cache <CACHE>`. Сервер только на loopback; Node.js и зависимости — по закреплённой базе. Открыть http://localhost:8892/. Это настоящий UI Lab с синтетическим HA, без подключения к дому.

Открыть Ground floor. Четыре дополнительных устройства находятся в гостиной; их настройки доступны через редактор устройств → «Отображение на плане». Для LED использовать «Свет в сауне». В опубликованном fixture высота LED исходная (Авто), для повтора проверки назначить 60 см. Для группировки использовать кухонный ряд и менять высоту «Духовой шкаф». После просмотра вернуть значение в Авто. Перспектива видна при переключении ракурсов.

Пакет не содержит браузерную сессию: ракурс и пользовательские эксперименты могут отличаться от PNG. Точные исходники и синтетический план сохранены; отдельный запуск с другого ПК при фиксации не выполнялся. Прототип принят, перенос в dev и продуктовые проверки остаются работой #1608.
