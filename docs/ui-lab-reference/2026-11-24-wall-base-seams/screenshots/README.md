# Происхождение снимков

before/01–09 — состояние перед исправлением швов, уже после правок основания. Это не кадры исходной беты для сравнения всех правок основания.
before/16 — промежуточный кадр, воспроизводящий растровый шов до его финального исправления.
before/owner-reported-window-joints.png — предоставленный владельцем 24.11.2026 фрагмент с искусственными вертикальными полосами под окнами (если исходный файл был доступен при фиксации).
after/23–32 — финальная принятая версия; 24-* — последовательность зума, 25 — кадр с активными растровыми слоями. 31 — альтернативный ракурс, 32 — общий вид.
after/verified-sections.jpg — контактный лист четырёх финальных участков, он кадрирован/масштабирован для обзора. Для деталей использовать исходные секционные JPEG.

Все браузерные снимки сняты при devicePixelRatio=2. API возвращает CSS-размер, не нативный физический размер окна. Снимки не являются машинными golden. Не включены неудачные промежуточные эксперименты, нативный снимок окна с чатом и обрезанные DOM/SVG дампы.
