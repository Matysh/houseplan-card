## Воспроизведение на другом ПК

Скачайте этот каталог целиком. Используйте отдельный чистый checkout продукта на указанном commit, чтобы не затронуть текущую работу. Пусть `REFERENCE` обозначает абсолютный путь к скачанному каталогу. Из корня такого checkout:

```sh
git apply <REFERENCE>/runtime-prototypes.patch
```

Скопируйте `accepted/lab-native-opening.ts` в `src/lab-native-opening.ts`. Затем:

```sh
npm ci --ignore-scripts
npm run build
npm run ui-lab:prepare
node <REFERENCE>/serve-reference.mjs --repo <CHECKOUT> --port 8892
```

При уже подготовленном HA frontend пропустите подготовку и передайте `--ha-cache <CACHE>`. Требуется Node.js 22. Сервер слушает только 127.0.0.1, на http://localhost:8892/ открывается штатный UI Lab со стандартными синтетическими данными. В редакторе плана можно нарисовать цепочку, выбрать стену, передвинуть узел или воспользоваться Resize. Данных/файлов владельца и подключения к его HA не требуется.

`serve-reference.mjs` — переносимый загрузчик для сохранённого слоя, не байтовая копия частного сервера. Он не переносит старую браузерную сессию. Снимки кода точные; воспроизведение пакета на другом ПК в момент фиксации отдельно не прогонялось. Фактические проверки сделанного прототипа перечислены в журнале. SHA-256 файлов — в `MANIFEST.json`.

## Что обязательно сохранить

Реальные опоры с обеих сторон; выносные линии от самого угла строго под 90° к стене; акцент HA только у параллельной размерной линии; три метрических знака; отсутствие «по оси» рядом с числом и старой толстой подсветки; синхронность размеров и отрисованного кадра во время движения. Наклонные выносы были отвергнуты и в финальный эталон не входят.

Этот пакет фиксирует UI, не закрывает задачу, не меняет её трек/статус, не доказывает полную корректность геометрии и не заменяет функциональные AC #1381. Числовой ввод не добавляется.


## Дополнение UI-057: обе комнаты при Resize

Владелец отдельно согласовал одновременный показ изменяемых боковых размеров обеих комнат при перетаскивании общей перегородки. accepted/native-proposals.mjs содержит этот обновлённый вариант; остальные адаптеры и база прежние. Подробности, AC и фактические проверки — UI-057 в JOURNAL.md. Предыдущий эталон UI-056 доступен в commit 4076cb742a64f341a9cac9589bf54b6312741dce. В синтетическом плане создайте две соседние комнаты с разрешённой общей границей, включите Resize и двигайте её в обе стороны: размеры нужны у обеих комнат одновременно. Escape убирает временный слой.
