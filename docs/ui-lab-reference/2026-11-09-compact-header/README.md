## Запуск с любого ПК

Нужны Git и Node.js 22 (исходная среда: 22.23.2). Используйте отдельные каталоги; команды ниже не переключают имеющиеся рабочие деревья. Внешний HA и авторизация не нужны.

```sh
git clone --branch issue/1371-ui-lab-reference-20261109 https://github.com/Matysh/houseplan-card.git houseplan-ui-reference
git clone https://github.com/Matysh/houseplan-card.git houseplan-ui-product
cd houseplan-ui-product
git checkout --detach 69a565c1fff387657b44ad9327dd2ab39cf4526b
npm ci --ignore-scripts
npm run bundle:sync
npm run ui-lab:prepare
node ../houseplan-ui-reference/docs/ui-lab-reference/2026-11-09-compact-header/serve-reference.mjs --repo . --port 8892
```

Открыть http://localhost:8892/. Остановка — Ctrl+C. `ui-lab:prepare` явно загружает официальный закреплённый HA frontend 20260930.4 (около 111 MB); если он уже подготовлен, этот шаг не нужен. Для другого каталога кэша добавьте `--ha-cache <каталог>` и при подготовке, и при запуске. После публикации issue содержит ссылку на неизменяемый commit материалов: при необходимости checkout reference-клона на него.

Сервер слушает только loopback и использует штатные offline-ограничения UI Lab. По умолчанию — только синтетические данные из закреплённого продукта, без чтения частных файлов. Никакой записи в настоящий HA. Сборка на диске не изменяется: локальный сервер преобразует несколько HTTP-ответов.

Запуск отклоняет другой HEAD, fingerprint или несовпавшие точечные anchors. Не исправляйте эталон под новый dev; для переноса используйте продуктовые исходники актуального dev. Fingerprint — исходной сборки, не изменённых сервером байтов.

Для сравнения «до» запустите отдельно из product-каталога:

```sh
npm run ui-lab -- --port 8893
```

Сравнивайте при одинаковой теме, языке, наборе данных и состоянии, в свежих браузерных сессиях двух портов. Сужайте окно до двух рядов и далее до компактного варианта, проверяйте меню, состояния hover, раскрытие/сворачивание и три редактора. Точные состояния описаны в ACCEPTED.md. Проверяйте анимации записью или покадрово. Базу не нужно пересобирать между состояниями.

## Разделение эталона и реализации

Патчи собранных чанков — временный быстрый механизм прототипа, не решение для продукта. Переносить в TypeScript, общие стили и UI Kit. Ориентиры перечислены в задаче. Служебный drawer UI Lab моделирует открытие sidebar HA только для иконки: реальная интеграция с HA требует отдельной проверки при реализации, включая закрытие через scrim/Escape/переход.

Адресные проверки, выполненные во время итерации, перечислены в журнале. Упаковка материалов не является повторным S6 или приёмкой релиза. Golden, baseline и продуктовые ветки не обновлялись.
