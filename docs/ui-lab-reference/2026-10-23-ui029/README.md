## Запуск

Нужны Git и Node.js 22. В отдельной папке:

```sh
git clone --single-branch --branch issue/998-ui-lab-reference-20261023 https://github.com/Matysh/houseplan-card.git houseplan-ui029-reference
cd houseplan-ui029-reference
npm ci
node docs/ui-lab-reference/2026-10-23-ui029/verify-package.mjs
npm run ui-lab:prepare
node docs/ui-lab-reference/2026-10-23-ui029/serve-reference.mjs
```

Открыть **http://localhost:8893/** → **UI LAB → Устройство → Отображение на плане → Иконка**. Рядом находятся образец «Способ отображения» и «Источник состояния значка». Для темы/языка доступна панель UI LAB; это не подключение к реальному HA. Закрыть сервер — `Ctrl+C`.

Можно указать проверенный кэш официального HA frontend: `--ha-cache /path/to/cache`, другой порт: `--port 8893`, отдельный закреплённый checkout: `--repo /path/to/clone`. Обычный запуск не скачивает файлы. Только явный `npm run ui-lab:prepare` загружает официальный runtime HA `20260930.4` с проверкой хэшей.

**Не пересобирайте эталон через `bundle:sync`.** База: commit `cd9c8961eb906a5c1492dedf2e245191de01cba5`, fingerprint `ccc0f18f7f4a7aa1e5106e6db0ba6cc8add2ab84d5369edd7b8c88f9d6e12074`. Launcher проверяет и копирует готовую опубликованную сборку из `custom_components/houseplan/frontend/` в `dist/`. Чужой/изменённый `dist/` не перезаписывается: нужен отдельный чистый клон. Настоящий icon picker загружается из того же официального модуля HA `53214`, что использовал принятый стенд.

## Как использовать при реализации

Текущее принятое ТЗ [#998](https://github.com/Matysh/houseplan-card/issues/998) обязательно, включая более позднее решение владельца: native floating popover на desktop и bottom sheet на narrow/low; зазор 7 px относится только к floating popover. Исторический архив не отменяет это уточнение и не доказывает соответствие всех ещё не проверенных состояний.

Запускайте эталон и кандидат отдельно на одинаковой синтетической сцене, теме, языке, viewport и состоянии. Не подключайте эти CSS/JS к кандидату: иначе они скроют его расхождения. DOM-наблюдатели и опрос старого стенда — временный механизм прототипа, не архитектура для переноса в продукт. Переключатель экспериментальных стилей в переносимой версии зафиксирован включённым: адаптер настоящего HA picker нельзя корректно отключить одним снятием CSS.

`JOURNAL-CYCLE.md` содержит историю всей итерации только как контекст. В #998 относится UI-029; UI-030/#999 и прочие правки не входят. Исходные локальные пути и проверочный скрипт с путями ПК автора не нужны для запуска этого пакета.

## Данные и проверка доставки

Частные fixture, состояния/реестры Home Assistant, сессии и исходные снимки плана **не опубликованы**. Используется публичная `demo/ui-lab/fixture.json` из закреплённого репозитория. Имена и хэши исключённых кадров остаются в `SOURCE-VERIFICATION.json` для происхождения, но это не сами изображения. Если AC требует именно исходный частный кадр, потребуется отдельная приватная передача; его нельзя подменить новым синтетическим снимком.

27.10.2026 отдельно проверен запуск этого пакета с опубликованной beta.1 и настоящим HA runtime: открыт диалог устройства и MDI popover, измерены высота поля **44 px** и зазор **7 px**, подтверждена подпись **«Поиск»**. Ошибок консоли при загрузке и раскрытии не было. Это smoke доставки, не повторная полная приёмка поиска, клавиатуры, выбора/сохранения, mobile или всех диалогов. Исходный объём проверок и его ограничения записаны в `SOURCE-VERIFICATION.json`.

Публикация материалов не возобновляет отложенную владельцем реализацию #998, не меняет её статус и не запускает релиз. Ветку эталона целиком в dev не сливать.
