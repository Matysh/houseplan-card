## Скоуп

Issue #532 (не изменился с r1): тройной `drop-shadow` внешнего контура плана
(`.hp-paperg`) жил в общем композиционном слое с планом, поэтому любая
перерисовка плана (ховер, панорама) заново прогоняла три прохода размытия по
габариту всего листа — в Firefox владельца ~9 к/с, 23 МБ текстур/кадр. Правка:
`will-change: filter` на `.stage.daycycle .hp-paperg, .hp-static-stage.daycycle
.hp-paperg`, уводящее отфильтрованную бумагу в свой слой. Побочный эффект
контракта (К2, принят спек-ревью r2): промоушен делит SVG на два слоя, отчего
диагональная штриховка стен антиалиасится иначе — 4 golden-кадра
`day-cycle-{dawn,day,dusk,night}-dark` расходятся и пересматриваются отдельным
коммитом на кандидате беты. Продуктовая рамка (View-режим как продукт для двух
персон, `docs/SCOPE.md`) не тронута этим раундом — перечитал `SCOPE.md`,
вывод не изменился.

Раунд r2 — это ровно исправление двух Medium-находок r1: оба чейнджлога и
`docs/SUN.md`. Продуктовый код (`src/styles/plan.styles.ts`), смок
(`demo/smoke_daycycle_raster.mjs`) и мутант (`scripts/mutation-gate.mjs`)
байт-в-байт не изменились с r1 — доказано ниже, не заявлено.
