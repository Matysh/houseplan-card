# Исторические ревью и свидетельства

[Индекс](INDEX.md) помогает найти прежние замечания и их контекст. Документы
ревью и каталоги `evidence-*` фиксируют конкретные версии, результаты и
ограничения; читать весь архив при входе в задачу не нужно.

Упомянутые в старых ревью процессные гейты, обязательные прогоны, трейлеры и
условия допуска относятся к прежней обвязке. Они не создают требований к
новому ревью и не поручают ревьюеру механические проверки.

Текущие правила — корневой [PROCESS.md](../../PROCESS.md), роль ревьюера —
[краткая памятка](../process/REVIEWER.md). Подготовка #1105 не означает, что
действующий процесс уже переключён.
