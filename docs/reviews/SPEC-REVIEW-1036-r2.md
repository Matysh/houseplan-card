## Находки

Находок уровня High/Medium в этом раунде не обнаружено.

**Low** (не блокирует; снимается записью ревьюера, §2.4/§2.7): таблица
критериев приёмки в теле issue разорвана пустой строкой между строками AC9 и
AC10 — новая строка `| AC10 | … |` идёт после пустой строки без собственной
шапки/разделителя, из-за чего при рендере Markdown это не продолжение прежней
таблицы AC1–AC9, а отдельный нераспознанный блок с пайпами (скорее всего
отрендерится как сырой текст, а не как таблица). Содержание самой строки
AC10 при этом читается однозначно — и как условие приёмки, и как способ
доказательства, — поэтому это не находка на проверяемость или двусмысленность
AC, которую обязано ловить ревью ТЗ, а чисто оформительская деталь. Оставляю
на усмотрение автора при следующей правке тела issue (убрать пустую строку
перед AC10, чтобы таблица осталась одной); вердикт не меняет.

Побочных находок вне скоупа этой задачи нет. Доверенный снимок
`HP_REVIEW_OUTSIDE_FINDINGS_FILE_ISSUES` (`mode=issues`) не задействуется —
заводить отдельные issue не для чего.

## Что проверено и корректно

- Оба Medium из r1 закрыты по существу, не декларативно: конкретный триггер,
  конкретное сообщение, конкретное поведение диалога и новый AC10 со своим
  smoke для первого; конкретная формулировка правки `docs/SCOPE.md` с теми же
  ограничивающими словами, что предлагал ревьюер r1, для второго.
- Новый текст не оставляет места для прочтения, при котором реализация могла
  бы молча захватить DOM редактора: единственная ветвь поведения на нажатие
  «Скачать» в SVG из редактора — показ сообщения и отказ от создания файла.
- AC10 имеет непустой столбец доказательства (smoke по trём режимам
  редактора) — соответствует требованию DoR §2.5 «у каждого [AC] указано, чем
  он доказывается».
- Термин «режим просмотра» в новом сообщении — штатная формулировка
  `docs/USER-GUIDE.ru.md`, не придуманная для этой задачи.
- Публикации кода по-прежнему нет: удалённая ветка задачи не содержит новых
  коммитов относительно материала r1 (между раундами в репозитории появились
  только три docs-коммита ревью по другим issue, не связанные с #1036) — это
  согласуется с комментарием автора «коммитов/публикации реализации нет».
- Гейты зелёные и идентичны по числам r1 (5571/1/0) — ожидаемо, так как
  продуктовый код между раундами не менялся; это не новое доказательство для
  AC (код задачи так и не существует), а подтверждение, что базовая кодовая
  база остаётся исправной для будущей реализации.
