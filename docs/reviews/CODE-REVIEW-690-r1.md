  (именно его не хватило #687 по тексту issue); список заморожен
  (`Object.freeze`).
- `selectSmokes()`: `visualMinimum` заполняется только при `unproven`, при
  доказанной связи (прямой или зарегистрированной) и при `noExecutableDiff`
  остаётся пустым — подтверждено фикстурами `unproven.diff`,
  `234-chain-thickness.diff`, `docs-only.diff`.
- `smokesToRun()` в `gate-small.mjs` включает `visualMinimum` в список для
  прогона наравне с `direct`/`registered`, с дедупликацией через `Set`.
- CLI (`report()`) печатает визуальный минимум отдельной громкой строкой

- `gate-small.mjs` итоговый лог называет причину («связь не доказана — …
  визуальный минимум (#690)») отдельно от обычного случая.
- Мутант `task-packet-trivial-is-product-flow` обновлён синхронно с
  изменением текста в `scripts/task-packet.mjs` — `find`-строка совпадает,
