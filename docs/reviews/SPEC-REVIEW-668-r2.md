## Что проверено и корректно (в этом раунде)

- AC4 больше не смешивает под одной пометкой «unit» два разных утверждения:
  теперь у равенства версии есть названный тест (извлечение и сравнение строк
  `Current for` / `Актуально для`, красный результат при расхождении версий),
  а у «RU/продукт не менялись» — метод «проверка diff», что для утверждения
  такого рода (по сути повторение Non-scope) остаётся приемлемым способом
  доказательства, не требующим отдельного автотеста.
- Правка не задела ни одну другую строку ТЗ: Scope, Non-scope, Contract,
  модель данных/i18n, AC1–AC3 и AC5–AC7, риски, откат и release-артефакты
  текстуально идентичны версии r1 — новых противоречий делта не вносит.
- Дельта учтена и в «Плане автотестов» (не только в таблице AC): формулировка
  теста на строку версии присутствует именно там, где ревью r1 требовало её
  найти, а не только в самой AC-таблице — расхождения между двумя разделами
  того же ТЗ, которое было сутью находки r1, больше нет.
- Материал не продвинулся дальше документа r1 в код — спек-ревью по-прежнему
  имеет дело только с текстом, преждевременной реализации нет.
