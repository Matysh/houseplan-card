## Скоуп и проверка изменения

Инфраструктура B/C: две строки определения одного мутанта, пояснения в
TESTING/STATUS и infra ledger. Прочитан полный дифф материала, исходный
`unionNodeEdgeBodies`, целевой геометрический тест и прежнее ревью #864.
Продуктовый код, тестовый oracle, workflow, runner, классификация outcomes
и правило ночного исполнения мутантов не меняются.

В [исходном ночном прогоне 38118204513](https://github.com/Matysh/houseplan-card/actions/runs/38118204513)
чистый guard прошёл, но мутант не подготовился: безусловный ранний return
сделал типизированный fallback недостижимым, TypeScript потерял сужение
`Geom | null` и выдал TS2345. Это setup-failure, не поимка и не дефект
пользовательской геометрии. Изменять продукт или принимать compile failure
за assertion-killed было бы неверно.

Новый патч заменяет только fallback-цикл `for (const quad of quads)` на
`for (const quad of quads.slice(0, 0))`. Коллекция пуста при любом числе
полос, поэтому replay целиком пропускается и возвращается исходный subject,
как предполагалось прежней поломкой. Fast path не затрагивается.
В отличие от раннего return, вызов slice оставляет тело цикла статически
достижимым и тип элементов неизменным; сужение nullable current сохраняется.
Это вывод по коду, не отчёт о компиляции применённого мутанта.
Якорь в исходном файле однозначен, что подтверждено статическим --check.
Id, guard, because и геометрический oracle сохранены.
