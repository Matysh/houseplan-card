## Проверка уточнения

Для каждого Q и общей C тождество union(Q ∩ C) = union(Q) ∩ C сохраняет
заполненное множество; комнаты, junctions, фасадная обрезка, shell, opening
cuts и следующие обязательные guards не исключены. Это только техническая
перестановка операций, не tolerance, упрощение модели или новый набор
разрешённых перемещений. В конечной арифметике тождество проверяется AC2/3,
не объявляется аксиомой библиотеки. Coverage остаётся прежним sufficient
proof: непроверенную полосу нельзя пропустить. Любой из трёх grouped failures
повторяет полную историческую фазу, с прежним покрытием уже растущим телом,
порядком и изоляцией отказа каждой полосы. AC2 имеет отрицательные пробы
для всех трёх этапов и для отказа отдельной полосы при fallback.

Критерий скорости остаётся final Linux CI; локальные числа не доказательство
AC4. Технический неудачный черновик не вносится в итоговый код. Новых
продуктовых вопросов, High/Medium нет. Гейты кода не являются материалом
этого spec-вердикта.
