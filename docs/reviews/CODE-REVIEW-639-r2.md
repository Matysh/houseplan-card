## Как проверялось (только то, что задевает дельта)

1. Прочитал diff `a3397329` целиком (8 строк) — единственное изменение в
   `demo/smoke_space_settings_form.mjs`.
2. Прочитал по коду путь коммита, который смок теперь проверяет:
   `src/editors/space-form.ts:428-431` — `#space-card-font` собран через
   `rangeLine({ min:50, max:300, step:5, slider: port.rangeInput(...), onInput: (n) => set(port, {...d, cardFontScale: n/100}) })`;
   `src/editors/form-kit.ts:470-489` — `rangeLine()` монтирует числовое поле
   с `onInput: () => undefined` (черновик не коммитится) и `onChange` →
   `committedRangeLineValue` → коммит. `150/100 = 1.5` — совпадает с
   ассертом `cardFontScale === 1.5`. Это тот же контракт, что ломался в
   #608, и теперь смок идёт через него, а не мимо.
3. Собрал бандл (`npm run bundle:sync`) — Validate этот прогон уже
   подтвердил на `a3397329`, но локальной копии `demo/srv/assets` не было,
   а без неё браузерные смоки не запускаются; пересборка нужна была для
   пункта 4, не для повторной проверки `tsc`/`build`.
4. `node demo/smoke_space_settings_form.mjs` на HEAD — `OK`, включая новые
   ассерты `fontDraftWaitsForChange`/`fontNumberCommitsThroughDom`,
   зарегистрированные в `checkAll(out)` (проверил `demo/serve.mjs:75-77` —
   `checkAll` требует `true` от каждого ключа объекта `out`, значит новые
   поля действительно участвуют в вердикте смока, а не просто вычисляются).
5. **Тест умеет падать**: временно вернул ровно правленые строки к

   без DOM-событий) — смок упал: `fontDraftWaitsForChange: expected true, got false`,
   `FAILED (1)`. Восстановил файл из бэкапа, `git status --short` пуст.
6. `node scripts/smoke-select.mjs --base origin/dev --head HEAD` — «браузерные
   смоки этим диффом не выбираются», диф не трогает `src/**` (как и в r1;
   инструмент подтверждает то же самое на новом материале).
7. `node --test test/smoke-select.test.mjs` — 7/7, реестр `smoke-links.mjs`
   структурно цел (символы/файлы существуют).
8. Сопутствующая регрессия дельты: прогнал `smoke_room_settings_form.mjs` и
