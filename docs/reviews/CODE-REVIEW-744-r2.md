## Унаследовано из r1

Продуктовый и тестовый код не менялся между r1 и r2 (делта — только
docs-коммит), поэтому нижеследующее из `docs/reviews/CODE-REVIEW-744-r1.md`

дело после ребейза, §2.10) принято без повторной проверки, с подтверждением
байт-в-байт по диффу `origin/dev...HEAD` текущего материала, а не только со
слов документа r1:

- Архитектура ключа (`src/floor-geometry-key.ts`, `floorGeometryKeyReader`) —
  отпечаток содержимого записи этажа (`contentFingerprint`), с кэшем на эпоху и
  на пару объектов записи (`model`/`current`); при расхождении переданного и
  текущего этажа ключ хэширует оба. Перечитан целиком заново в этом раунде —
  содержимое файла идентично тому, что описывает r1.

  `configEpoch: number`; `test/clean-floor.test.mjs` обновлён под неё.

  `_cleanFloorCache` — подтверждено диффом, комментарий `#744` на месте.

  корректном порядке относительно `session.accepted`/`publish` — разобрано r1
