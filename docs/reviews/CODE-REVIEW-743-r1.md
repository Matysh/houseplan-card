## Находки

### Medium — AC3 доказан не на финальном материале

**Файл/контекст:** хендофф-комментарий issue #743, раздел «AC3»; коммит
`d73b1782` (`demo/performance/budgets-large-house-isometric-backdrop.json`).

**Воспроизведение.** АС3 требует: «Full Performance на ветке … все профили
зелёные, включая isometric-backdrop». Автор ссылается на прогон
`36869442701`, сам же помечая его «на `9e323303` (до второго коммита)».
Второй коммит `d73b1782` — не косметика: он меняет `hardMaxMs` метрики
`switchCycleMs` бюджета этого профиля с `8000` на `1550`, то есть ужесточает
именно тот защитный потолок, который АС3 должен подтвердить зелёным. Прогон
`36869442701` исполнялся на SHA `9e323303`, когда в бюджете ещё стоял
`8000` — почти на три порядка мягче. Единственный прогон Full Performance
этой ветки (подтверждено `gh run list`) состоялся **до** правки,
закрывающей собственно эту защиту; на `d73b1782` (материал ревью) AC3 не
исполнялся ни разу.

**Почему это не бухгалтерия (не Low).** `switchCycleMs.hardMaxMs` —
защитный AC в терминах промпта (лимит/отказ): граница, которую новый
прогон мог бы не пройти, а никто не проверил. Риск не гипотетический:
собственный локальный свидетель автора по АС1 (до бюджетного коммита)
называет `switchCycleMs` ветки `1687` мс — уже выше итогового `1550`,
пусть и с оговоркой «локально, 2 CPU, рядом другие агенты — диагностика,
не доказательство» (так помечено в исследовательской части самого issue).
На CI-раннере показатель может оказаться другим в любую сторону, но именно
поэтому нужен реальный прогон на `d73b1782`, а не экстраполяция.

**Чем закрывается.** Один свежий `workflow_dispatch` `performance.yml` на
`issue/743-bench-iso-backdrop` (ветка не меняется, ≈4 минуты — прогон
`36869442701` занял `3m50s`) с зелёным `isometric-backdrop` на `d73b1782`
(или более новом коммите того же содержания). Если он красный по
`switchCycleMs` — обсуждаемо: вернуть `hardMaxMs` к значению,
подтверждённому прогоном, либо прогнать достаточно образцов, чтобы медиана
легла в `1550` с варьируемым `noiseAllowanceMs=250`.

**Серьёзность:** Medium, в скоупе задачи — чинится автором в этой же ветке
без выделения отдельного issue (§12). Без High это жёлтый вердикт и
повторный цикл.
