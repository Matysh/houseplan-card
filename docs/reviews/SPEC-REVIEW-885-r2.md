## Разбор дельты r2

Фактическая проверка добавленного текста:

- `docs/CANVAS.md` действительно содержит §9.3 «What snaps, and to what» с
  описанием и Walls-резолвера («The Walls tool adds one architectural
  resolver before the free grid fallback… After architectural snapping, a
  Walls segment within `0.25°` … is made exact … (#290)», строки 543–556), и
  строки NODE-MOVE-резолвера («`resolveNodeMoveSnap`: frozen original axes
  and exact incident-wall H/V goals before the free grid fallback», строка
  519) — оба места, которые задача меняет по контракту п.3–4, попадают под
  формулировку «порядок приоритета резолвера Walls и `resolveNodeMoveSnap`»
  из добавленного пункта release-артефактов. Пункт называет верный документ и
  верную область правки, новой неоднозначности не вносит.
- `docs/USER-GUIDE.ru.md` действительно использует термин «стены нулевой
  толщины» (строки 302, 1076, 1294) и нигде не содержит отдельной сущности
  «виртуальная стена» применительно к стенам — инструкция «писать «стены
  нулевой толщины», а не «виртуальные стены»» в разделе «Релизные артефакты»
  фактически точна.
- Оба добавления — чисто документационные дополнения существующего раздела
  «Релизные артефакты»; они не меняют контракт, не меняют ни один AC и не
  расширяют скоуп. Это соответствует тому, как r1 описал способ закрытия
  («чисто документационное дополнение ТЗ... правка возвращается автору тем
  же issue»).
- Новых открытых вопросов владельцу в последних двух авторских комментариях
  (2026-10-13T23:00:38Z, 2026-10-13T23:37:41Z) нет; трек подтверждён автором
