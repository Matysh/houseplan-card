## Что перепроверено в этом раунде

Дельта — правка процесса гейтов в «Плане автотестов», не поведенческая. Она не задевает
доказательство ни одного AC (AC1…AC9 остаются описывать *что* доказывается; правка меняет
только *когда* один из способов доказательства обязан быть исполнен). Поэтому по правилу
«заново проверять только те AC, чьё доказательство дельта задевает» — предметных AC для
повторной проверки нет.

Проверено отдельно, поскольку это прямой предмет находки r1:
- новая формулировка не создаёт новое противоречие — `demo/smoke_furniture.mjs` назван
  обязательным именно там же, где AC1/AC3/AC4/AC6 называют его доказательством (раздел
  «Критерии приёмки», не менявшийся в дельте): `docs/specs/361-furniture-stroke-zoom.md:183,
  190, 194, 203`;
- `golden`, полный набор browser smoke, `performance_smoke` и полный gate остались
  предрелizными, как и было в r1-версии — эта граница дельтой не сдвинута, значит регрессии
  §11.4 (предрелизные гейты не подменяют код-ревью) нет;
- трейлеры коммита `31c6e77c`: `Issue: #361`, `User-Visible: no` — корректно, изменение
  докс-only и не видно пользователю продукта.
