## Что проверено и корректно

- Обе находки r1 закрыты текстом, а не ссылкой/обещанием автора — проверено
  построчным чтением итогового текста (см. «Закрытие раунда r1»).
- Новый раздел «Принято предположительно, поменять свободно» по форме и
  содержанию соответствует реально используемой в проекте конвенции
  (issue #1029, раздел 13) — не самодельный формат.
- Новая спецификация disambiguator не оставляет недоказуемых случаев для
  реалистичных данных: совпадение минуты (секунды), совпадение секунд из-за
  перевода часов (offset), полное совпадение timestamp при неразличимой
  identity (explicit ambiguous). Случай «совпадающий ровно до секунды exact
  timestamp при различимой identity» физически недостижим для предметной
  области (завершения уборок разнесены на минуты, не на доли секунды) —
  непропорционально требовать для него отдельного эталона.
- Правка строго аддитивна: не затронула таблицу состояний кнопок, lifecycle,
  контракт record/map, AC2–AC6, AC8–AC9, архитектуру, модель данных, i18n,
  откат, release-раздел — перепроверка по дельте (§2.10) не требовала их
  повторного разбора.
- SHA материала подтверждён (`git rev-parse HEAD` = `4c3e7e95c98e3223c8c2c7fcc2dde3a01a83b7ea`,
  совпадает с заявленным в задаче), лейблы issue (`S4-spec-review`,
  `track:ask`) соответствуют этапу/треку этого ревью.
