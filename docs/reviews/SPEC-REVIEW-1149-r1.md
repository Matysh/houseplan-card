## Скоуп ревью

ТЗ описывает третий пакет миграции содержимого диалогов настроек на общий UI Kit: выбор
цвета/прозрачности (`hp-color-opacity.ts`), предпросмотр устройства, тумблер сводной (вместе
с правкой побайтовой фикстуры `test/form-kit.test.mjs`), Zigbee-textarea и удаление мёртвого
non-embedded CSS, кнопки «+/-» тревог устройства (icon-button из пакета 1), inline-стиль внешних
экранов, координатные поля радара (`tempin`) и `.rhint`/`.warn` → `callout()` для маршрутов
пылесоса. Задача обслуживает J4 `docs/SCOPE.md` («настройка плана через GUI» — единообразие и
доступность контролов внутри административных диалогов); бэкенд, модель данных и алгоритмы
(цвет/тревоги/диагностика/карты) не меняются.
