## Находки

### M1 (Medium, в скоупе задачи) — `demo/smoke_danger_confirmation.mjs` не переведён на ожидание составного гейта; диалог опасного действия может быть незаметно потерян при переключении языка

**Файлы:** `demo/smoke_danger_confirmation.mjs` (не тронут этим коммитом — единственный из смоков, синхронно переключающих язык поверх открытого редактора/онбординга, который автор пропустил в списке из девяти переведённых на ожидание гейта); причина в `src/houseplan-card.ts:1968-1973` (`_syncDangerConfirmLocaleGate`) и `src/houseplan-card.ts:4033-4036` (авто-отмена на `warm`, #417).

**Дефект:** `_syncDangerConfirmLocaleGate` теперь берёт составной рантайм загруженной поверхности (`_editorRuntime?.languageRuntime ?? _onboardingRuntime?.languageRuntime ?? LANGUAGE_RUNTIME`), а не только основной каталог. Существующий с #417 механизм «отменить `_dangerConfirm`, если гейт вернул `warm`» из-за этого расширения начинает срабатывать и в момент, когда основной каталог уже осел (тест ждёт именно это условие: `card._t('btn.cancel') !== expectedCancel`), а словарь пространства (`settings`) на этом же хосте — ещё нет: составной гейт остаётся `pending` → рендер-цикл видит `warm` (хост уже был `committed` на английском) → `_cancelDangerConfirm()` срабатывает синхронно, до того как диалог успевает отрисоваться. Вызывающий код получает `false` без единого кадра диалога и без какой-либо видимой подсказки — не «английская вспышка», которую ТЗ прямо предвидело в разделе «Риски», а тихая потеря запроса подтверждения.

**Воспроизведение:**
1. `npm run build && node scripts/bundle-sync.mjs`.
2. `node demo/smoke_danger_confirmation.mjs` — падает необработанным исключением внутри `localeFits('de', …)`: `TypeError: Cannot read properties of undefined (reading 'click')` (воспроизвелось на первом прогоне в чистой сессии; из ~8 последующих прогонов подряд — 0 падений, гонка зависит от относительной скорости загрузки чанков `de.ts` и `settings-de-*.js`).
3. Детерминированное воспроизведение (не закоммичено, только для диагностики): в копии смока добавлена задержка 40 мс на ответ `**/settings-de-*.js*` через `page.route` перед вызовом `localeFits('de', 'Abbrechen')` — падение стабильно повторяется на каждом прогоне.
4. Контрольный прогон на `origin/dev` (`22c7d634`, до #627) в отдельном воркчасти: тот же смок проходит зелёным («OK», все поля true) — регрессия точно привязана к этому диффу, а не к окружению.

**Чем краснеет** (защитное свойство «диалог опасного действия не теряется при переключении языка поверхности»): задержка ответа любого из девяти namespace-чанков (`settings`/`support`/`topology` × ru/de/fr) относительно основного каталога — продемонстрировано выше для `settings`-`de`.

**Почему Medium, а не High:** прямой угрозы безопасности нет — потерянный запрос разрешается в `false` («не подтверждено»), ни одно деструктивное действие не выполняется без подтверждения; в реальном UI хост становится `inert` на время `warm`, что обычно блокирует пользовательский клик в этом же окне. Но это реальная, воспроизводимая регрессия существующего регресс-смока (он попал в «прямое совпадение» инструмента `smoke-select` и напрямую относится к вводимому этой задачей контракту), она интермиттентна и не поймана ни одним мутантом (гвард `danger-confirm-uses-last-rendered-language-gate` — другой файл, `smoke_danger_confirm_branches.mjs`, который эту гонку не задевает) и ни одним юнит-тестом; оставленная как есть, она будет время от времени красить полный смок-прогон перед бетой в зависимости от таймингов сети/чанков — именно то, что процесс просит ловить на этапе код-ревью, а не на релизном гейте.

**Почему в скоупе, а не отдельным issue:** ломающий смок и вызвавшая его причина — прямое следствие ядра этой задачи (составной гейт по словарям пространств), тот же риск, что ТЗ называет в разделе «Риски» («смоки… нужно перевести на ожидание гейта, а не ослаблять проверки»); чинится он тем же приёмом, что уже применён к девяти другим смокам в этом коммите.

**Вердикт по AC:** не относится ни к одному конкретному AC1–AC7 напрямую (это не то поведение, которое AC описывают), но затрагивает общий контракт задачи «поверхность не мигает английским / не виснет» — в данном случае «не молчит вместо диалога».

Low/иных находок нет.
