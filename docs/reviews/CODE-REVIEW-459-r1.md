## Проверка по AC

- **AC1** (кружок у заголовка, наведение/фокус/клик) — подтверждено чтением: `render()` кладёт `${this._t('title')}${this._help()}` в `.section` (строка 187), а не в `.toggle`. Открытие по наведению/фокусу/клику — поведение самого `hp-help.ts`, не тронутого этой задачей, доказательство ссылкой корректно.
- **AC2** (fail-closed без одного из ключей) — `_help()` проверяет `hasTopologyTranslation(lang, 'help')` и `...'help_aria'`, возвращает `nothing`. Тест `кружок справки не рисуется без подписи для скринридера` гоняет `hasTopologyTranslation` напрямую, включая случай `no_such_key` → `false` и англ. фолбэк для `de`. Мутант `topology-help-renders-without-aria` (правит резолв на `?? key`, имитируя старую фиктивную проверку) пойман.
- **AC3 / AC3b** (шесть+один пункт легенды по-русски) — тест проверяет 10 паттернов по нормативной ru-строке, все совпадают: LQI, 40, 180, пунктир, исходящая→координатор, входящие, «без стрелки», «подпись на конце стрелки», «отсутствие стрелки», «дерево маршрут», «не путь пакета». Мутант `topology-help-drops-arrow-legend` (вырезает предложение про стрелки) пойман.
- **AC4** (границы шкалы = `lqiColor`, не константа) — тест импортирует `lqiColor` из скомпилированного `logic.js` и берёт hue(40)=0, hue(180)=120 из функции, затем ищет те же числа в тексте. Подтверждено чтением `logic.ts:8-10`: `hue = clamp(0..120, (lqi-40)/140*120)` — ровно то, что описывает ТЗ.
- **AC5** (нет переносов строк) — проверено для всех четырёх словарей; строки `help`/`help_aria` непустые.

## Низкие находки (без блокировки, приняты с запиской)

1. **Расхождение отчёта с диффом:** автор пишет «+22 утверждения в шести новых тестах», в дифе — семь новых тестов (`AC1`…`AC6`, `AC3b` отдельно). Чисто редакторская неточность в отчёте, не в коде; не влияет на проверяемость.
2. **`data-help-key` не проставлен.** Оба существующих места, где строится `<hp-help>` (`houseplan-editor-runtime.ts:1232`, `houseplan-onboarding-runtime.ts:58`), кладут `data-help-key=${key}` — по этому атрибуту `demo/smoke_help_affordance.mjs` находит конкретный кружок. Новый локальный `_help()` в `hp-zigbee-topology-settings.ts` этот атрибут не ставит. Ни один AC его не требует, поведение кружка не страдает — но если когда-нибудь понадобится смок, целящийся именно в этот кружок, привычный селектор `hp-help[data-help-key="..."]` не сработает. Не блокирует, реализатор может добавить одной строкой при желании.
3. **Гейт паритета словарей уехал из плана.** ТЗ ожидало «несколько строк в существующем тесте» (`test/i18n.test.mjs`), реализация — новый тест в `test/zigbee-topology.test.mjs`. Гейт работает (проверил падением), но заявленный в «Затронутых файлах» путь не совпал с фактическим — организационная, не функциональная деталь.

Ни одна находка не блокирует и не относится к Medium: ни AC, ни продуктовое поведение не задеты.

- Performance-профили — не названы в AC и не задеты диффом.
- Остальные 222 браузерных смока — не выбраны инструментом (`НЕОПРЕДЕЛЁННОСТЬ`) и не относятся по теме к namespace-компоненту без побочных эффектов; единственный релевантный (`smoke_zigbee_topology_hover`, AC8) прогнан.
