## Материал и исключение

Материал: `044f09a6a5eee277b3cdd4b3b1e9c1ef46232e79`, база
`v1.79.0-beta.1` (`dca0fd2876d318b84edb3d97889e19fb384b8139`).
Прочитаны все 13 ship-задач из детерминированного входа
[36965602182, attempt 3](https://github.com/Matysh/houseplan-card/actions/runs/36965602182).
SHA-256 `ship-issues.json`: `1c4cf2671f5b2dcc05b65dd8fc53a66909d6d306762dc98812e9169ab582d162`.
Патч-наборы в машинном блоке взяты из этого входа, не составлены вручную.

Штатная модель дважды закончила до чтения кода: `is_error=true`, один ход,
нулевой расход, нет `structured_output`. Отдельный повтор model-job также
не дошёл до модели из-за отсутствующего входного артефакта новой попытки.
Явного сообщения об исчерпании лимита в доступном логе нет. Владелец отдельно
разрешил самостоятельное ship-ревью при таком отказе и продолжение выпуска.
Этот документ — результат ручного ревью, а не зелёный результат упавшего CI.

## Проверки и защитная сила

- `npm run bundle:release`: typecheck, сборка и синхронизация кандидата прошли в WSL.
- `npm test`: 3540 тестов, 3510 passed, 30 skipped, 0 failed. Первые два
  локальных запуска отказали только из-за промежуточного Git-индекса собранных
  чанков: тест читает manifest из HEAD, а список tracked из индекса. Индекс
  возвращён к HEAD без изменения рабочего дерева; полный повтор зелёный.
- `node --test test/windows-portability.test.mjs`: Windows, 7/7 passed;
  тот же файл исполнен в полном Linux-наборе.
- `node --test --test-name-pattern=#718 test/moon.test.mjs`: WSL, 6/6 passed.
- Браузерные смоки WSL, каждый `node demo/smoke_<имя>.mjs`: 20/20 прошли:
  `warm_mode_adoption`, `warm_dialogs`, `nav_persist`, `moon`, `moon_static`,
  `moon_status`, `room_fill_transitions`, `floor_geometry_cache`,
  `iso_floor_switch`, `isometric_contract`, `isometric_live_touch`, `stairs`,
  `lazy_editor_chunk`, `space_card`, `device_hit_capsules`,
  `dialog_polish_603`, `backdrop`, `german_locale`, `daycycle_layer_budget`,
  `dialog_footer_width`.
- `npm run benchmark:isometric-stage3-dense`: прошёл наблюдаемый контракт,
  включая отсутствие nudged overlays и структурных пересборок на живых
  обновлениях. Это диагностический локальный замер, не сравнение с base-SHA.
- `npm run docs:accept -- --identical`: все 11 кадров pixel-identical.
  Обновлён только исходный fingerprint; PNG и golden-baselines не менялись.
- `node scripts/mutation-gate.mjs --check`: проверка реестра, без исполнения
  мутантов. Мутант `summary-area-recomputes-walls-per-room` прямо убирает
  передачу `shared.roomGeom, shared.multiWallNodes` и связан с тестом #721.
- Проверены диффы оракулов: #708, #712, #715, #722 и #759 сохраняют прежние
  сравнения, а не заменяют их проверкой наступления ожидаемого результата.
  #734 дополнительно запрещает пустой набор наблюдений; #719 проверяет ноль,
  а не просто снимает прежнее требование. Для #733 и #760 отрицательные случаи
  входят в исполненные юниты. Проба старого box model #712 встроена в смок.

58 задач линии. Полный HA-harness, весь набор golden и все смоки локально

прочитаны. Локальный бенчмарк не заменяет Linux CI performance proof.
