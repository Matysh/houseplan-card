## Скоуп

Свидетель #525 (`demo/smoke_space_switch_transitions.mjs`) ловил мутант
`device-markers-rendered-without-keys` через побочный признак: отсутствие
бегущего перехода `box-shadow` на `.device-shell-frame` после переключения
пространства. #524 убрал этот переход из стилей (перф-регрессия Firefox),
признак стал тривиально истинным, и позиционное переиспользование DOM-узлов
маркеров перестало ловиться — свидетеля ослепили не намеренно, а как
побочный эффект соседней задачи.

Задача #528 узкая: маркерная половина свидетеля должна судить по идентичности
узла (`data-id` привязанного к узлу до/после переключения), а не по анимации.
Дверная половина (`op-leaf`/`op-arc`) остаётся как есть — там переход часть
продуктового контракта (#525) и её не просили трогать.
