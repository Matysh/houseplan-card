## Скоуп

Инфраструктурная задача (`infra`/`tests`/`process`/`tech-debt`/`bug`, P2), трек `ask` по прямому запросу владельца — явное исключение из обычного ускоренного входа инфраструктурных задач на `S7` без ТЗ (AGENTS.md «Трассируемость»/«Трек»: «инфраструктура … skips analysis and spec»). Предмет: фактическая версия запущенного headless Chromium как условие визуального доказательства (сейчас `toolchain-pins.mjs` проверяет только наличие пути, не версию исполняемого бинарника), диагностика нестабильных golden/smoke-кадров (F40/F41/F47), расширение `visual:render`-риска на `live-hover.ts`/`device-battery.ts`/`zigbee-topology.ts`/`hp-zigbee-topology-overlay.ts` и автодобавление `ci:golden` контроллером при обнаруженном и непокрытом визуальном риске (F48).

Привязка к `docs/SCOPE.md`: задача не продуктовая и прямо это признаёт («Сопровождение J1/J2/J7, без изменения пользовательского UI»; раздел 6 ТЗ — UX/конфиг/API/i18n/миграция не меняются). Это допустимо: SCOPE.md ограничивает продуктовые фичи, а не достоверность собственного CI-конвейера; обоснование «обслуживает J1/J2/J7» достаточно для инфраструктурного railguard-а.
