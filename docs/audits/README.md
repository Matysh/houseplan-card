# Исторические аудиты

Аудиты хранят выводы о конкретном материале, исходные данные и решения по
найденным проблемам. Их читают при работе с соответствующей областью;
это не список обязательных действий для каждой задачи.

Процессные команды и требования старых аудитов отражают прежнюю обвязку.
Не переносить оттуда дополнительные гейты или условия допуска на текущие
задачи. Продуктовые результаты и доказательства сохраняют свой контекст.

Актуальный порядок описан только в [PROCESS.md](../../PROCESS.md).
