## Основное

- На больших планах тяжёлая сцена больше не перестраивается при каждом hover,
  pan, pinch и перетаскивании в редакторах, а нерелевантные обновления Home
  Assistant не вызывают полный render; внешний вид и поведение сохраняются,
  отклик становится заметно плавнее
  ([#451](https://github.com/Matysh/houseplan-card/issues/451)).
- Мелкие исправления и улучшения.

## Highlights

- Large plans no longer rebuild the heavy scene on every hover, pan, pinch or
  editor drag, while unrelated Home Assistant updates no longer trigger a full
  render; visuals and interaction semantics stay unchanged while response is
  noticeably smoother
  ([#451](https://github.com/Matysh/houseplan-card/issues/451)).
- Small fixes and improvements.
