## Основное

- Почти перпендикулярные T-стыки больше не оставляют белые клинья и сохраняют исходный небольшой уклон стены.
- Backend теперь принимает только доказанное перепривязывание проёмов при удалении совпадающей перегородки через «Оптимизировать планы».
- «Оптимизировать планы» безопасно убирает точные лишние перегородки поверх внешних стен, после чего доступный Resize действительно двигает общую стену; неподвижные ручки больше не выглядят активными.
- Мелкие исправления и улучшения.

## Highlights

- Nearly perpendicular T-junctions no longer leave white wedges and preserve the wall's original small slope.
- The backend now accepts only a proved opening reattachment when Optimize plans removes a coincident partition.
- Optimize plans safely removes exact redundant partitions over outer walls, after which an eligible Resize handle actually moves the shared wall; immovable handles no longer look enabled.
- Small fixes and improvements.
