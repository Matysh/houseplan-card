## Основное

- Четыре диалога настроек полностью приведены к макетам дизайнера: единые карточки и контролы, один скролл, понятная валидация, сохранение только при изменениях и подтверждение закрытия несохранённой формы ([#600](https://github.com/Matysh/houseplan-card/issues/600)).
- Мелкие исправления и улучшения.

## Highlights

- The four settings dialogs now fully match the designer reference: one shared card-and-control language, a single scrollbar, clear validation, Save only after changes, and confirmation before discarding an edited form ([#600](https://github.com/Matysh/houseplan-card/issues/600)).
- Small fixes and improvements.
