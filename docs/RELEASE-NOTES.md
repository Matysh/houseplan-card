## Основное

- Связи Zigbee по сведениям ZHA/Zigbee2MQTT вместо расчётного дерева: сплошные стрелки, плавная шкала качества сигнала и явные отметки неизвестных или устаревших данных ([#798](https://github.com/Matysh/houseplan-card/issues/798)).
- Оптимизировано свечение LED-лент при зуме: свет остаётся видимым, полное качество автоматически возвращается после остановки ([#789](https://github.com/Matysh/houseplan-card/issues/789)).
- Мелкие исправления и улучшения.

## Highlights

- Zigbee links use ZHA/Zigbee2MQTT reports instead of an inferred tree: solid arrows, a smooth signal-quality scale and explicit unknown or stale data indicators ([#798](https://github.com/Matysh/houseplan-card/issues/798)).
- Optimized LED-strip Glow while zooming: light stays visible and full quality returns automatically when zooming stops ([#789](https://github.com/Matysh/houseplan-card/issues/789)).
- Small fixes and improvements.
