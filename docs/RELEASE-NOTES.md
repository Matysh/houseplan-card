## Основное

- `houseplan-space-card` получила плотное кадрирование по конструкции дома, а её Glow больше не пересобирает сцену с нуля на каждый тик Home Assistant ([#373](https://github.com/Matysh/houseplan-card/issues/373), [#375](https://github.com/Matysh/houseplan-card/issues/375)).
- Цвет и стиль по умолчанию для новых элементов подложки теперь сохраняются вместе с планом и переживают перезагрузку ([#377](https://github.com/Matysh/houseplan-card/issues/377)).
- В режиме «Значение + состояние» можно выбрать точный источник показания — например, позицию шторы `42 %` вместо её текстового состояния ([#378](https://github.com/Matysh/houseplan-card/issues/378)).
- Мелкие исправления и улучшения.

## Highlights

- `houseplan-space-card` now offers tight whole-house framing, while its Glow no longer rebuilds the scene from scratch on every Home Assistant tick ([#373](https://github.com/Matysh/houseplan-card/issues/373), [#375](https://github.com/Matysh/houseplan-card/issues/375)).
- The default colour and style for new Background objects are now stored with the plan and survive a reload ([#377](https://github.com/Matysh/houseplan-card/issues/377)).
- **Value + state** can use an exact reading source — for example, a cover position of `42 %` instead of its textual state ([#378](https://github.com/Matysh/houseplan-card/issues/378)).
- Small fixes and improvements.
