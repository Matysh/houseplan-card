<!-- release: v1.69.0-beta.2 -->

## Основное

- Полностью обновлена библиотека мебели: 56 видов сверху и удобный двухуровневый выбор категории и варианта ([#159](https://github.com/Matysh/houseplan-card/issues/159)).
- Исправлено определение температуры и влажности комнаты по фактическому размещению датчиков, а физические выключатели без собственной сущности теперь корректно показывают активность ([#317](https://github.com/Matysh/houseplan-card/issues/317), [#318](https://github.com/Matysh/houseplan-card/issues/318)).
- Редактор устойчивее переживает сетевые сбои и обновления, а сервер защищает планы и позиции устройств от перезаписи устаревшими вкладками ([#340](https://github.com/Matysh/houseplan-card/issues/340), [#353](https://github.com/Matysh/houseplan-card/issues/353), [#356](https://github.com/Matysh/houseplan-card/issues/356)).
- Мелкие исправления и улучшения.

## Highlights

- Completely refreshed the furniture library with 56 top-view symbols and a convenient two-level category and variant picker ([#159](https://github.com/Matysh/houseplan-card/issues/159)).
- Fixed room temperature and humidity selection by actual sensor placement; physical wall controllers without their own entity now show activity correctly ([#317](https://github.com/Matysh/houseplan-card/issues/317), [#318](https://github.com/Matysh/houseplan-card/issues/318)).
- The editor now survives network failures and updates more reliably, while the server protects plans and device positions from stale browser tabs ([#340](https://github.com/Matysh/houseplan-card/issues/340), [#353](https://github.com/Matysh/houseplan-card/issues/353), [#356](https://github.com/Matysh/houseplan-card/issues/356)).
- Small fixes and improvements.
