## Основное

- «Проём» теперь открывает компактное подменю «Окно / Дверь / Ворота» и показывает полный полупрозрачный предпросмотр будущего объекта ([#75](https://github.com/Matysh/houseplan-card/issues/75), [#76](https://github.com/Matysh/houseplan-card/issues/76)).
- Исправлено закрытие редактора с первого нажатия ([#95](https://github.com/Matysh/houseplan-card/issues/95)).
- Мелкие исправления и улучшения.

## Highlights

- **Opening** now provides a compact Window / Door / Gate sub-menu and a complete translucent placement preview ([#75](https://github.com/Matysh/houseplan-card/issues/75), [#76](https://github.com/Matysh/houseplan-card/issues/76)).
- Fixed editor closing on the first click ([#95](https://github.com/Matysh/houseplan-card/issues/95)).
- Small fixes and improvements.
