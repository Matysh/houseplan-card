## Основное

- Четыре основных диалога настроек стали проще для просмотра: связанные поля собраны в карточки, пояснения открываются по «?», а короткие варианты видны сразу в сегментированных переключателях ([#594](https://github.com/Matysh/houseplan-card/issues/594), [#598](https://github.com/Matysh/houseplan-card/issues/598)).
- Библиотека мебели полностью перерисована в едином стиле и расширена до 60 видов сверху; добавлены компьютер, вытяжка, духовка и кактус ([#593](https://github.com/Matysh/houseplan-card/issues/593)).
- У устройств появился режим «Значение + статичный значок»: значение остаётся видимым, а цвет иконки не меняется от состояния ([#588](https://github.com/Matysh/houseplan-card/issues/588)).
- Мелкие исправления и улучшения.

## Highlights

- The four main settings dialogs are easier to scan: related fields are grouped into cards, explanations open from “?”, and short choices are immediately visible as segmented controls ([#594](https://github.com/Matysh/houseplan-card/issues/594), [#598](https://github.com/Matysh/houseplan-card/issues/598)).
- The furniture library was fully redrawn in one style and expanded to 60 top views, adding a computer, cooker hood, oven and cactus ([#593](https://github.com/Matysh/houseplan-card/issues/593)).
- Devices gained a “Value + static icon” mode: the value stays visible while the icon colour no longer changes with state ([#588](https://github.com/Matysh/houseplan-card/issues/588)).
- Small fixes and improvements.
