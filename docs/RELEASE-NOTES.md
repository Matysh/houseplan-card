## Основное

- Диалоги настроек надёжнее сохраняют черновики, проверяют обязательные поля рядом с вводом, поддерживают удобное посимвольное редактирование чисел и корректно работают в оболочке Home Assistant ([#607](https://github.com/Matysh/houseplan-card/issues/607), [#608](https://github.com/Matysh/houseplan-card/issues/608), [#609](https://github.com/Matysh/houseplan-card/issues/609), [#610](https://github.com/Matysh/houseplan-card/issues/610), [#614](https://github.com/Matysh/houseplan-card/issues/614)).
- Импорт, экспорт и хранение стали безопаснее для больших конфигураций: тяжёлые операции не блокируют Home Assistant, а маршруты робота корректно переносятся вместе с копией пространства ([#611](https://github.com/Matysh/houseplan-card/issues/611), [#625](https://github.com/Matysh/houseplan-card/issues/625)).
- Исправлены повседневные сценарии: read-only просмотр больше не требует прав администратора при обновлении устройств, жесты на сенсорных экранах точнее, а у посудомоечной машины обновлена иконка в палитре ([#612](https://github.com/Matysh/houseplan-card/issues/612), [#613](https://github.com/Matysh/houseplan-card/issues/613), [#640](https://github.com/Matysh/houseplan-card/issues/640)).
- Мелкие исправления и улучшения.

## Highlights

- Settings dialogs now preserve drafts reliably, validate required fields beside their inputs, support smooth multi-digit number editing, and behave correctly inside Home Assistant's dialog shell ([#607](https://github.com/Matysh/houseplan-card/issues/607), [#608](https://github.com/Matysh/houseplan-card/issues/608), [#609](https://github.com/Matysh/houseplan-card/issues/609), [#610](https://github.com/Matysh/houseplan-card/issues/610), [#614](https://github.com/Matysh/houseplan-card/issues/614)).
- Import, export and storage are safer for large configurations: heavy operations no longer block Home Assistant, and robot routes now follow a copied space correctly ([#611](https://github.com/Matysh/houseplan-card/issues/611), [#625](https://github.com/Matysh/houseplan-card/issues/625)).
- Everyday use is more robust: read-only views no longer demand administrator access when devices refresh, touch gestures target reliably, and the Dishwasher palette icon has been refreshed ([#612](https://github.com/Matysh/houseplan-card/issues/612), [#613](https://github.com/Matysh/houseplan-card/issues/613), [#640](https://github.com/Matysh/houseplan-card/issues/640)).
- Small fixes and improvements.
