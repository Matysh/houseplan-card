## Релиз Houseplan 1.83.1

Срочное исправление создания комнат и оптимизации плана.

После обновления комнаты создаются в замкнутых контурах с округлёнными стыками сразу, без предварительного Optimize. Оптимизация сохраняет примыкания стен и проёмы и не вызывает связанную с этим ошибку сохранения. [#1166](https://github.com/Matysh/houseplan-card/issues/1166)

## Houseplan 1.83.1 release

An urgent fix for room creation and plan optimization.

After updating, create rooms immediately inside closed contours with storage-rounded joints, without running Optimize first. Optimize preserves wall contacts and openings and avoids the related save error. [#1166](https://github.com/Matysh/houseplan-card/issues/1166)
