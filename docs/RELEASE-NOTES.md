## Основное

- Возврат на вкладку и восстановление соединения больше не могут навсегда скрыть готовый план; все динамические данные обновляются одним согласованным кадром.
- Мелкие исправления и улучшения.

## Highlights

- Tab resume and connection recovery can no longer permanently cover a complete plan; all dynamic data now updates as one coherent frame.
- Small fixes and improvements.
