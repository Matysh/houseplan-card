## Уточнение относительно #1026

Последнее явное решение владельца: **«выключено — полупрозрачна только иконка, недоступно — весь кружок»**. Оно заменяет визуальную трактовку из ТЗ #1026; нельзя переносить старую схему «unavailable приглушает только иконку» обратно.

Не смешивать Power Off с `binary_sensor.off`, `unknown`, отсутствующим показанием или недоступностью чужой управляемой сущности. Использовать общий разрешённый факт собственной доступности и корректно определённое питание устройства, включая составные устройства; подпись и оформление должны использовать один результат. Ограничение прототипа (Power Off по основной сущности) не является продуктовым контрактом. Существующие lifecycle/static/live gates сохраняются. Специальная геометрия LED в этой итерации не переопределялась.

## Критерий приёмки

**Результат соответствует согласованным UI-прототипам всех девяти правок выше** при одинаковых теме, данных, режиме, масштабе и ширине House Plan.

- [ ] Совпадают внешний вид, тексты, отступы, слои, hover и анимации; поворот и закрытие сравниваются с живым replay, а не только со статичными кадрами.
- [ ] Для вращения совпадают пристенные и свободные группы с разными бейджами во всех четырёх ориентациях; фон неподвижен.
- [ ] Статусы «Выключено»/«Недоступно» и обычный вид совпадают с UI-007 r3, подписи им соответствуют.
- [ ] Соблюдаются точные границы **1480**, **1120**, **1024 px по контейнеру House Plan**, в том числе внутри HA с боковым меню; это не ширина окна браузера.
- [ ] Карточка и настройки панели используют общий UI Kit; свечение отключено только в двух согласованных редакторах.

Прототипы — визуальный эталон, не готовая архитектура для копирования: DOM-observer, подмена методов runtime и загрузка всего editor runtime ради UI Kit являются локальными приёмами лаборатории. Продукт интегрируется в существующие компоненты. Новые продуктовые решения за пределами согласованного визуала не подразумеваются.

Частный бекап, план реальной инсталляции и локальная браузерная сессия не входят. Кадры заново сняты на синтетическом плане; это иллюстрации финальных прототипов, а не снимки исходного частного плана. Поворот групп и динамические эффекты следует смотреть в живом replay.

## Запуск на другом компьютере

Нужны Git и Node.js 22. Скачать этот каталог из закреплённого commit отдельно от базового checkout.

```sh
git clone https://github.com/Matysh/houseplan-card.git houseplan-ui-base
cd houseplan-ui-base
git checkout --detach 09bda8dbee8b50577bfc4affc332b8cda914f5b4
npm ci
npm run bundle:sync
npm run ui-lab:prepare
node /path/to/this/package/replay.mjs --repo . --port 8892
```

Открыть http://127.0.0.1:8892/. В панели UI LAB выбрать русский язык и тёмную тему. `--ha-cache PATH` позволяет использовать уже подготовленный HA runtime. Авторизация HA и личный бекап не нужны. Replay делает временную копию стенда, берёт чистый app.mjs из закреплённой базы и добавляет только девять адаптеров этого пакета. Остановка — Ctrl+C. Для чистого исходного состояния использовать новый порт/профиль браузера: UI Lab сохраняет пользовательские изменения локально.

Команды подготовки приведены для получателя; при упаковке этой визуальной итерации тестовые наборы, сборка и CI не запускались.

## Как смотреть эталон

1. В просмотре повернуть план в обе стороны. Фон остаётся неподвижным, движение — 280 мс. Для контуров в редакторе устройств собрать магниты в две группы: пристенную и свободную в центре комнаты; включить асимметричный бейдж значения. Сравнить все четыре ориентации. Контур должен заново охватывать вертикальные относительно экрана бейджи. Частный пример согласования заменён этим воспроизводимым сценарием.
2. Контекстное меню устройства → **Карточка устройства**. Сравнить оболочку, строки, ссылки, отступы и футер. Обычное нажатие может открывать HA more-info — это другая карточка.
3. Показать скрытые устройства; красная и серая точки должны перекрывать край кружка. Красную точку можно воспроизвести устройством, ещё не отмеченным известным в данных стенда; скрытую — действием **Скрыть** в контекстном меню.
4. Открыть **Настройки сводной панели**, навести на крестик. Сравнить закрытие крестиком, Escape и Отмена. Крестик — из общего UI Kit.
5. Сравнить свечение в просмотре, редакторе устройств, редакторе плана и подложки. В последних двух оно скрыто.
6. Навести на **Умный выключатель** (выключен), **Недоступный датчик** и обычное устройство. Третья строка соответственно **Выключено**, **Недоступно** или отсутствует. Сравнить прозрачность внутреннего значка и целого маркера.
7. Менять именно ширину контейнера House Plan: 1480/1481, 1120/1121 и 1023/1024 px. Для обзорных кадров использованы 1600, 1280 и 1000 px. Проверить все три редактора; при пересечении последнего порога сохраняется текущий черновик свойств.

## Замечания для исполнителя

UI-005: токены отступов HA в theme.css компенсируют окружение автономной лаборатории. Это не основание менять глобальные токены продукта. На локальном стенде штатное закрытие согласовано; предположение о старом HA-крестике на реальной инсталляции не является доказанной диагностикой её причины.

UI-010: прототип подменяет getter ширины и дополняет наблюдение за 1024 px. В продукте порог должен быть согласован в штатных вычислениях и обработчике изменения размера, а не добавлен вторым observer.

UI-007: Power Off по основной сущности — ограничение демонстрационного адаптера. Для составных устройств разрешение питания должно соответствовать продуктовой модели, с тем же визуальным результатом. Прозрачность нельзя умножать повторно внутри уже полупрозрачного недоступного маркера.

Исходники адаптеров сохраняются как визуальный эталон. Их DOM-наблюдатели и подмена runtime-методов не предписывают архитектуру реализации.
