## Границы

- **Это дизайн-референс, а не продуктовый код.** JS прототипа не переносится:
  `localStorage`, демонстрационные пространства, устройства и списки остаются
  здесь. `reference/room-fill.test.mjs` — проверка автора на семантику заливок,
  CI её не запускает.
- **В бандл отсюда не попадает ничего.** Проверяется `bundle-tree`.
- **Приоритет при расхождении** (`SPEC.md` §2): ТЗ в теле #600 > действующие
  контракты House Plan (данные, безопасность, доступность, `hp-dialog`, touch) >
  визуал и взаимодействия прототипа > детали реализации прототипа.
- **Два решения владельца расходятся со `SPEC.md` автора** и имеют приоритет над
  ним: образцы карточки комнаты остаются (Q2), поле цвета получает новую
  раскладку, но прежний контрол `hp-color-opacity` без нативного пикера (Q5).
