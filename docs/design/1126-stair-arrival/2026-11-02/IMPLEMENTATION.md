# Перенос в продукт

Прототип: runtime/app.mjs::installStairArrival1126 и блок #1126 в overrides/houseplan-card.css. Событие лестницы отмечает исходный этаж, после успешного штатного _tabClick добавляется временный SVG-контур на все обратные лестницы, без изменения камеры и сохранённых данных.

В продукте реализовать явное состояние прибытия в общем runtime лестниц/навигации (src/stairs-view.ts, src/houseplan-card.ts), вывод через Lit, общий тематический токен --hp-accent. Использовать существующую геометрию лестниц. Учитывать смену этажа любым способом, редакторы, повторный переход, перерисовку, отключение компонента и reduced motion; очищать таймеры/состояние. Для 2.5D подтвердить, что индикация попадает в отображаемый слой проекции, а не только в скрытый SVG. Сохранять ограничения фиксированного этажа, навигационные guards и защиту от ложного клика после жеста.

Лабораторные capture-обработчики, обёртки приватных методов, DOM append, CSS polling и остальные прототипы не переносить. Общие стили и движение оформить через существующие уровни UI Kit/общей темы. Это визуальная передача: Flat показан на синтетическом replay; матрица 2.5D, тем, touch, киоска и reduced motion остаётся проверкой продуктовой реализации.
