# Погодный виджет — утверждённый визуал #1174

[Контракт](CONTRACT.md) · [Перенос в продукт](IMPLEMENTATION.md) · [Исходная постановка](ORIGINAL_ISSUE.md)

Получить ветку codex/1174-approved-ui репозитория Matysh/houseplan-card. Требуются Git, Node.js 22+, PowerShell на Windows либо unzip на Linux/macOS. Из корня checkout:

~~~sh
node demo/ui-lab/prepare-ha.mjs
node docs/design/1174-weather/2026-11-02/replay.mjs --repo . --port 18974
~~~

HA frontend готовится один раз. Дополнительные параметры: --ha-cache PATH и --release-zip PATH. Replay скачивает официальный ZIP 1.84 Beta 2 и проверяет SHA256. npm install и сборка не нужны. Остановка Ctrl+C.

Основной адрес: http://127.0.0.1:18974/HousePlan
Карточка: http://127.0.0.1:18974/dashboard
Киоск: http://127.0.0.1:18974/HousePlan?hpkiosk=1

Погода уже включена; настройки находятся в «Настройки сводной панели». Для просмотра других состояний добавить параметр weatherPreview (в киоске через &):
- only — погода без остальных блоков;
- multiple — два источника, выбор рядом с галочкой;
- none — нет источников;
- unavailable — выбранный источник недоступен;
- partial — только текущая погода без дополнительных показателей/прогноза;
- deleted — ранее выбранная сущность удалена.

Например: http://127.0.0.1:18974/HousePlan?weatherPreview=only

Настройки демонстрации сохраняются в localStorage отдельно для каждого сценария. При загрузке погодного сценария панель показывается для удобства просмотра; это поведение стенда, не новое продуктовое требование. Существующие блоки не удаляются в сценарии only.

fixture.json и погодные значения публичные синтетические. Частный бэкап, HA доступ и данные реальной установки отсутствуют. runtime/ и overrides/ сохраняют согласованный интерфейс, screenshots/ — иллюстрации на синтетическом плане. approval/journal/provenance фиксируют согласование, решения, базу и SHA256.
