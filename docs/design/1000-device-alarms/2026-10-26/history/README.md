# История визуальной итерации

Эти снимки сохранены для контекста и **не являются итоговым макетом**. Финальные экраны находятся в [../screenshots/](../screenshots/).

Порядок изменений:

1. `table.png`, `constructor.png` — первый набросок таблицы и конструктора.
2. `table-create.png` — добавлена кнопка «Создать» в пустом состоянии.
3. `constructor-ui-kit.png` — конструктор переведён на общий UI-kit.
4. `condition-help.png` — добавлена стандартная подсказка у «Условие».
5. `alarm-outcome.png` — выровнен колокольчик и добавлено описание будущего поведения тревоги.
6. `alarm-outcome-plain.png` — заголовок сокращён до «Включится тревога», разделитель между блоками убран.
7. `dialog-backdrop.png` — добавлен отсутствовавший в offline-стенде токен затемнения.

`intent.json` — сохранённая черновая запись требований; её прежний статус `draft-awaiting-owner-review` относится к моменту создания. Актуальное согласование и состав пакета записаны в [../provenance.json](../provenance.json) и [../README.md](../README.md).
