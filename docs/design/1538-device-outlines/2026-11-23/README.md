# #1538 — согласованный визуальный прототип обводок 2,5D

Владелец согласовал результат 23.11.2026 и поручил зафиксировать его в задаче. Продуктовая реализация ещё не выполнена. Критерий приёмки: соответствие согласованному прототипу и решениям ниже.

Основа: `3aa45b00ca8755c1a515fc17e29f2eeaf026aff8` (dev, 1.86.1-beta.4). `prototype.patch` содержит итоговый локальный diff семи файлов `src`, включая все исправления итерации. Это воспроизводимый прототип, не готовый к слиянию продуктовый патч.

## Принятые решения

- Контур строится единообразно в плоскости плана, затем проецируется целиком. Прямые концы у стен не получают отдельного сдвига, создающего косые хвосты.
- Поддерживаются свободные и пристенные одиночные устройства/группы, прямые и наклонные стены, углы и группы вдоль двух стен. Геометрия пересчитывается для текущего ракурса.
- Перекрытые стенами части оболочки, верхней/нижней кромки и торцов полностью скрываются. Никакого просвечивания через стену.
- Задняя половина оболочки и её кромки за устройствами; передняя — поверх корпусов. Каждая половина рисуется один раз: без швов и усиления прозрачной заливки повторным наложением.
- Основное значение и дополнительные плашки, включая «Выключено», поворачиваются вместе со своей подложкой вокруг её собственного измеренного центра. Текст не выходит наружу. Экструзия остаётся вертикальной на экране.
- Для пристенного устройства смещается визуальный центр: ближайший к стене край сохраняет прежний зазор при повороте. Размеры основных и дополнительных плашек учитываются совместно; в углу учитываются обе стены. Масштабирование не сбрасывает смещение.
- Контур, маски и взаимодействие должны учитывать актуальное представление. Поворот не меняет сохранённые позиции и принадлежность группам. Flat и редакторы сохраняют поведение.
- Общие изменения реализуются через общие механизмы геометрии и представления; UI Kit, размеры и токены переиспользуются там, где применимо. Не добавлять исключения под конкретную строку, датчик или ракурс.

## Материалы

- `prototype.patch` — точные итоговые изменения исходников.
- `fixture.json` — синтетический план с двумя пространствами обводок (а также штатными демо-этажами) и примерами прямых/наклонных стен, углов, свободных/пристенных/угловых групп и широких значений. У прямой стены добавлен пример `320 lx` + `Выключено` для последней правки.
- `replay.mjs` — переносимый запуск штатного offline UI Lab, по умолчанию порт 8892.
- `overview.jpg`, `frontal.jpg` — новые иллюстрации итоговой сборки на синтетическом плане. Они иллюстрируют результат, но не являются автоматически принятыми golden-кадрами.
- `SPEC.md` — копия ТЗ из задачи на момент фиксации.

Реальная резервная копия, идентификаторы устройств пользователя, локальные пути и снимки его плана не опубликованы. Приёмка происходила также на частном восстановленном плане; синтетический пример позволяет повторить геометрические случаи без него.

## Воспроизведение на другом компьютере

Нужны Git, Node.js 22 и npm. Ветка материалов основана на указанном dev и не содержит продуктовых изменений `src`: они лежат только в patch.

```sh
git clone --branch codex/ui-lab-dev-20261123 https://github.com/Matysh/houseplan-card.git houseplan-1538
cd houseplan-1538
git apply docs/design/1538-device-outlines/2026-11-23/prototype.patch
npm ci --ignore-scripts --no-audit --no-fund
node node_modules/rollup/dist/bin/rollup -c
node demo/ui-lab/prepare-ha.mjs
node docs/design/1538-device-outlines/2026-11-23/replay.mjs
```

Открыть http://127.0.0.1:8892/HousePlan. Выбрать «Обводки · 2,5D» или «Обводки · наклонные стены» в списке пространств; переключать восемь ракурсов кнопками вращения. При необходимости передать `--port 8893` или `--ha-cache /path/to/cache`. Подготовка HA загружает штатные ресурсы его интерфейса в локальный кэш; подключения к реальному HA нет. Остановка — Ctrl+C.

Если используется другой checkout, сначала сохранить пакет и применить patch к точной основе выше. На изменившемся dev исполнитель переносит общие решения осознанно, а не заменяет файлы целиком.
