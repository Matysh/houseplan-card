# Согласованный конструктор профилей #1165

[Визуальный контракт](CONTRACT.md) · [Точки реализации](IMPLEMENTATION.md). Полная копия локального прототипа на 1.84 Beta 2 с публичными синтетическими данными. Исходный частный бэкап не нужен и не включён.

## Запуск на любом ПК

Получить ветку codex/1165-approved-ui репозитория Matysh/houseplan-card. Нужны Git, Node.js 22+, PowerShell (Windows) или unzip (Linux/macOS). Из корня checkout:

~~~sh
node demo/ui-lab/prepare-ha.mjs
node docs/design/1165-profile-constructor/2026-11-02/replay.mjs --repo . --port 8893
~~~

Подготовка HA нужна только при отсутствии кэша. Можно передать --ha-cache PATH обеим командам. Replay скачивает официальный ZIP v1.84.0-beta.2, сверяет SHA256 и распаковывает во временный каталог; для локального архива передать --release-zip PATH. npm install и сборка не требуются. Тег содержит старый tracked frontend: использовать именно проверяемый ZIP релиза, не заменять его frontend-каталогом тега.

- http://127.0.0.1:8893/HousePlan — основной план, несколько пространств.
- http://127.0.0.1:8893/HousePlan?profilePreview=single — сокращённый конструктор для одного пространства.
- http://127.0.0.1:8893/dashboard — карточка с полными редакторами; параметр single работает и здесь.

Открыть Общие настройки → Внешние экраны → Создать (либо Добавить при существующих профилях). В режиме single только конструктор получает одно пространство: реальные данные fixture не удаляются. Переключение полного/сокращённого вида выполняется URL, не удалением пространств. Остановка Ctrl+C. Локальные данные replay хранятся в localStorage; восстановить исходный снимок можно в UI LAB на этом синтетическом стенде.

## Состав

- runtime/ и overrides/ — полный финальный локальный прототип.
- fixture.json — синтетический пример из ранее опубликованного пакета #1132.
- screenshots/ — новая фиксация полной/сокращённой формы и стыков разделителей на синтетических данных.
- journal.json, approval.json — перечень итоговых решений и согласование.
- provenance.json — закреплённая база, происхождение и SHA256 материалов.

Runtime также содержит ранее согласованный фон #1207, необходимый для точного воспроизведения текущего стенда. Объём задачи #1165 определён P01–P10/K01–K04, прежние UI-001–UI-019 не добавляются повторно. Этот пакет — визуальная передача исполнителю; не продуктовый патч и не подтверждение прохождения продуктовых тестов.
