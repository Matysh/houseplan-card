# Вертикальный центр видимых букв и SVG

Один обычный пробник измеряет нарисованные пиксели текста отдельно от line box.
В неизменённом опубликованном ecbb1e520a63cbef0fe6033d270dfd2643cdfc4b из64сочетаний 48 показывают
смещение; дефект наблюдается во всех четырёх footer. После исправления64/64PASS.
Максимальное смещение видимых букв: 0.5px; SVG: 0px.
Пороги одинаковы до/после:1,25px для букв и0,25px для SVG. Они не подгонялись.

Матрица:4диалога ×4языка ×1280/390px ×HA/унаследованный стек с line-height2.1.
HA использует его настоящий Roboto. Унаследованный профиль задаёт Segoe UI/Roboto/Arial;
эта Linux-проверка не утверждает наличие системного Segoe. Шрифты продукта не меняются.
Сохранённые данные не изменились, ошибки/внешние обращения0. Входы до/после
побайтово совпадают; хеши и все числовые измерения приложены.

Для воспроизведения: свежий demo bundle в обычных checkout обоих материалов и
один probe.mjs, запущенный с --root=/checkout --helpers=/after --out=/tmp/proof
--label=before или after. Компоненты HA настоящие, автономные; без реального HA,
авторизации, устройств или утверждения о field/GPU-приёмке. Измеряется настоящий
Save каждого диалога, включая старый код без нового label-wrapper. Src не подменяется.
