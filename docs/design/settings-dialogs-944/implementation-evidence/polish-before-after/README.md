# Девять замечаний: обычный старый код и исправленная реализация

Это проверка полировки #955 на реальных компонентах HA, отдельно от сравнения
с согласованными макетами и от golden-приёмки. Старый код не подменяется и
не модифицируется. Исходные SHA, деревья, хеши пробника и типографики записаны
в `before.json`, `after.json` и `evidence.json`.

Один пробник на старом опубликованном `ecbb1e52` воспроизводит все девять
замечаний; на исправленной реализации все девять проверок проходят:

1. Перенос подписи показа Zigbee-связей не оставляет короткий обрывок строки.
2. «?» показывает подсказку сразу при hover, имеет pointer и видимое выделение.
3. Начало оконных лучей выбирается двумя превью без дублирующего списка.
4. Тумблеры и подписи выровнены по вертикали.
5. Над текущим состоянием луны нет лишнего разделителя.
6. Значение прозрачности 100 помещается вместе с native stepper.
7. Высота оболочки не зависит от внутренней прокрутки раздела.
8. Рамка hover кнопки «Как в теме» не обрезается.
9. Обе кнопки подтверждения отмены используют общий hover.

В обоих случаях сохранённая конфигурация после отмены осталась неизменной;
ошибок страницы и внешних обращений нет. Синтетический вход одинаков:
`103b09ac2cb56a1bda19b67484272717d9568e52bab3512bad1ed9c450ee78ab`.
Файл `synthetic-data.json` содержит только данные автономного demo.

Для воспроизведения нужны два обычных checkout указанных материалов, их
зависимости и свежий demo bundle (`npm run bundle:sync`). Пробник не пишет в
исходники, не меняет пороги или эталоны. Типографика берётся из одного и того
же helper исправленной ветки для обеих сторон:

```sh
node /path/to/after/docs/design/settings-dialogs-944/implementation-evidence/polish-before-after/probe.mjs --root=/path/to/before --typography-root=/path/to/after --out=/tmp/polish-proof --label=before
node /path/to/after/docs/design/settings-dialogs-944/implementation-evidence/polish-before-after/probe.mjs --root=/path/to/after --typography-root=/path/to/after --out=/tmp/polish-proof --label=after --input=/tmp/polish-proof/before-data.json
```

Первая команда ожидаемо заканчивается ненулевым кодом и девятью `false`,
вторая — кодом 0 и девятью `true`. Детали измерений и 12 PNG приложены.
Проверка не доказывает приёмку физического телефона, GPU или настоящего HA.
