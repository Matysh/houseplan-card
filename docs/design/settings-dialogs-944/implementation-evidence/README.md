Общие элементы отвечают одинаково: hover и pointer, открытие списков,
подсказки, колор-пикер, тумблеры, кнопки и подтверждение отмены. На узком
экране боковое меню заменяется выбором раздела. Форма комнаты остаётся одной
формой. Цвета берутся из темы HA; проверены светлая, тёмная и пользовательская
палитры, ширины 320/390/1280 px и высота 480 px.

По сравнению со старыми формами уменьшилась необходимость помнить, где
находится параметр и почему он отличается в другом пространстве. Сохранены
существующие границы сохранения, источники и вычисления. Однако обещать полное
отсутствие изменений поведения нельзя: согласованы CO₂, независимые размеры,
переопределение заряда, связанная видимость границ/проёмов и удаление старых
переключателей. Эти исключения описаны в задачах и CONFIG-COMPATIBILITY.

Реальные MDI-иконки и штатный пикер отличаются от условных значков макета.
Серое отключённое поле, унаследованное значение, состояние Zigbee и доступность
источника света отражают реальные данные и права. Такие состояния не заменены
декоративными значениями ради совпадения картинки. Подсказки сведены к общему
голубому элементу согласно последним правкам, даже где старый макет оставлял
серый фон. Бейджи «Отдельная операция» и «Применяется сразу» убраны согласно
прямому указанию; границы самих операций сохранены.

Один неизменный пробник на прежней опубликованной реализации воспроизводит
смещение в48случаях из64; на исправленной —64/64PASS. Входные данные и хеши
пробника совпадают. Подробности и кадры — в [save-before-after](save-before-after/README.md).
Последняя
проверка измеряет пиксели букв и центр SVG, а не только текстовый контейнер.
На русском смещение букв 0 px, на остальных языках не более 0,5 px.
Отдельные отрицательные наблюдения выявляли низкий текст, зазор 41 px после
подзаголовка радара и лишнюю строку в навигации пространства; исправления
проверены повторным обычным сценарием. Для этой полировки проверена готовность
реестра; новые определения мутаций не исполнялись.

Дополнительный просмотр пар обнаружил два разделителя перед LED-действием:
внутренняя строка наследовала рамку и отступы старого футера. На неизменённом
кандидате новая обычная проверка воспроизвела дефект во всех12сочетаниях
темы/viewport; после снятия старого оформления —12/12PASS. Вложенная строка
теперь выровнена с полями, разделитель принадлежит общему блоку. Внешний вид
остальных футеров не менялся. Это исправление найдено сравнением с макетом,
а не изменением эталона под реализацию.

Просмотр первого полного golden-комплекта обнаружил ещё одну связанную ошибку:
расширенное поле вмещало100, но сокращалась подпись «Прозрачность» или
«Интенсивность». Комплект не принят. Шесть обычных проверок на неизменённом
коде воспроизвели обрезание; после выделения подписи её полной ширины они
прошли. Размер числового поля сохранён, свободное место получает ползунок.
Повторные304native и полная8-сценарная матрица прошли; настройки и отмена
сохраняют прежний контракт.

В CI эти наблюдения дополняют `smoke_settings_polish_955`,

Предрелизный полный CI обнаружил, что последовательный запуск всех восьми
сценариев `smoke_settings_polish_955` превышает общий лимит одного процесса
180 секунд. Проверки перенесены без изменений в
`demo/helpers/settings-polish-955.mjs`; четыре обычных smoke-entry запускают
по два случая. CI по-прежнему исполняет все восемь сценариев, каждую тему,
размер экрана, hover, подсказку, picker и сохранение/отмену. Лимит не увеличен.
Команды полного набора:

```sh
node demo/smoke_settings_polish_955.mjs
node demo/smoke_settings_polish_room_sensor_955.mjs
node demo/smoke_settings_polish_led_climate_955.mjs
node demo/smoke_settings_polish_vacuum_radar_955.mjs
```

Существующий аргумент `--case=<name>` сохранён для диагностики одного случая;
`--fast` и `--geometry` не заменяют полный набор. Старый signal-policy smoke
также исправлен: перед кликом переключателя он открывает Appearance через
видимую навигацию, как пользователь. Прежние проверки наследования и записи
не изменены. Причины исходных отказов и команды повторов записаны в #947/#955
по PROCESS.md §11.4; продуктовый код и эталоны при этих исправлениях не менялись.
