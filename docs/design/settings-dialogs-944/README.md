Скачайте нужный HTML кнопкой Download raw file в GitHub и откройте в браузере. Это самостоятельные документы; подключение к Home Assistant не нужно. По умолчанию во всех четырёх макетах открыт вариант «После». Внизу сравнения можно перейти к реконструкции «Сейчас», внутри — навигация по разделам. Черновики открываются на пространстве «1 этаж · жилой», раздел «План и масштаб»; сверху можно выбрать комнату или устройство.

«Сейчас» — реконструкция формы по коду, а не screenshot продукта. Данные синтетические, baseline `104a63f1e218eede610dd621a62346ceb3eab2e6`. Все проектируемые гарантии определяются текстом issue, а не демонстрационным обработчиком кнопки.

## Изменения черновиков v7

Общие настройки v10 не менялись. В пространстве:

- «Заменить» и «Уже загруженные» расположены в один ряд.
- Переключатель границ сразу включает/выключает обводку и проёмы, включая ворота. При миграции старых настроек видимость проёмов приравнивается к разрешённой видимости границ (`show_borders` с прежним default; `hide_openings = !resolvedBorders`). Ожидания клика и промежуточного состояния нет; геометрия и расчёт света сохраняются.
- Поле называется «Стены нулевой толщины (виртуальные стены)».
- «Комфортная температура» — заголовок; под ним одна строка «От [min] До [max]».
- CO₂ в предпросмотре показывает «CO₂ 820 ppm» без атомной иконки. Остальные четыре иконки остаются; данные CO₂ по-прежнему planned #920.

Набор содержит 333 записи: 332 значения совпадают с v6; одно намеренно изменено миграцией проёмов. Исходное false сохранено отдельно для варианта «Сейчас». Предыдущая полировка, два размера, цепочка заряда и старт с «После» сохранены. Подробности находятся в [инвентаризации](draft-decisions.md) и #945. Продуктовый код не изменён.

## Сохранённая полировка элементов

- Во всех вариантах «После» доступные кнопки, списки и ссылки имеют pointer и заметный hover; состояния фокуса сохраняют нативный outline. Проверены кнопки нижнего ряда, действия, навигация, подсказки, цветовые popover, раскрываемая диагностика и выбор сценария.
- Недоступные элементы показывают not-allowed, без активного hover. Текстовые поля сохраняют курсор text. Основные и опасные действия сохраняют свой смысловой цвет.
- Списки открываются и закрываются за 160 мс с изменением прозрачности и transform (`translateY(-5px) scale(.985)` → обычное положение). Стрелка поворачивается. Меню имеет радиус 10 px и отступ 5 px; варианты — отступы 10 × 12 px, hover и отметку выбранного значения. Поддерживаются клавиатура, Escape и закрытие снаружи. Учитывается reduced motion.
- В черновиках доступные списки работают локально, сохраняя тип значения и зеркалируя данные «Сейчас / После». Три readOnly списка Glow остаются недоступны. Отмена восстанавливает последнее сохранённое значение; немедленные настройки пылесоса не откатываются общей отменой.

## Совместимость списков

Макет использует [native customizable select](https://developer.mozilla.org/en-US/docs/Learn_web_development/Extensions/Forms/Customizable_select) внутри `@supports (appearance: base-select)`. В браузерах без этой возможности остаётся обычный нативный список: выбор и клавиатура работают, оформление меню и его анимация зависят от браузера. Это ограничение демонстрационного макета.

В продукте нужен одинаковый согласованный UX в поддерживаемых браузерах. При необходимости использовать существующий компонент списка Home Assistant или совместимый компонент проекта; не переносить ограничение `base-select` из макета в критерии приёмки продукта.

## Согласованность и ограничения

- **Общие v10** сохраняют согласованный v9, включая отсечение внешнего оконного луча откосом; обновлена подсказка о наследовании заряда. 47 общих записей до/после; намеренные исключения — сброс стен/севера и две настройки удаляемого затемнения (#943).
- **Три остальных диалога v7** остаются черновиками компоновки. Сохранены 12 сценариев и 329 исходных записей; четыре новых after-only записи доводят набор до 333. В «После» восемь прежних контролов убраны/заменены намеренно; изменение видимости проёмов — явное исключение миграции с сохранённым исходным значением для «Сейчас».
- Изменения в примерах локальны. Кнопки не запускают реальное сканирование Zigbee, загрузки HA, импорт или удаление данных. Автоопределение ZHA/Z2M описано в #948; фиксированная демонстрация содержит обе системы.
- Производственное сохранение, отмена, права, ошибки и транзакции реализуются по issue и существующим контрактам. Два ползунка пространства и два ползунка комнаты с числовым вводом работают локально; превью комнаты учитывает соответствующие базы пространства; поля комфортной температуры также работают в локальном черновике; остальные текстовые/числовые поля вне цветового popover фиксированы; отдельные операции и сбросы демонстрационные.
- Ссылка на конвертер и её описание реализуются в #948; #938 закрыта как дубликат #948. Возможности самого конвертера остаются в #937.
