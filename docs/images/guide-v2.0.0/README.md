# House Plan v2.0.0 screenshots / Скриншоты House Plan v2.0.0

The English and Russian guides use 26 matching scenes per language. The
captures use the frontend from the published [House Plan v2.0.0
archive](https://github.com/Matysh/houseplan-card/releases/tag/v2.0.0) in the
House Plan panel with a synthetic home. The WebGL view and device-height
scenes show the same example home and devices as the rest of the guide.

В руководствах 26 одинаковых сцен на каждом языке. Кадры сняты в панели House
Plan с интерфейсом из опубликованного [архива v2.0.0](https://github.com/Matysh/houseplan-card/releases/tag/v2.0.0)
на вымышленном доме. На новых кадрах показаны объёмный вид и поле высоты
устройства.

- Chromium 151.0.7922.34, device scale factor 1, reduced motion.
- Light Home Assistant theme and pinned Home Assistant frontend 20260729.7.
- PNGs were compressed losslessly with oxipng.
- [Capture provenance](PROVENANCE.md) lists the release SHA, archive checksum,
  build fingerprint, viewport and hash for each image.
