## Implementation

The frozen picker uses endpoint Merge first, finite eligible receiving IDs,
Draw's along-host quantizer and graphDrawTargetRef exact reprojection. Radius
and ambiguity use the final point: 12 CSS px and a 1 CSS px distance tie between
different identity/material carriers. No target leaves ordinary Move in charge;
an ambiguous eligible target refuses atomically. A click/zero displacement
never attaches. The split ID is allocated once at down with LAN-safe crypto.

The new optional attach_edge is mutually exclusive with merge_node_id and
requires wall_node_attach_api:1. It is not stored in model11. Held frames paint
bounded source outline/host/target only. Release builds the graph once, preserves
source ID, original.from -> source as the old edge and source -> original.to as
the allocated child, remaps both room-cycle orientations and opening tq, and
rebinds or retires affected fixed-point dependencies. Foreign exact points do
not propagate. Only the named source/receiving children gain a contact exception.

The global length guard measures a whole collinear run. The named split also
checks both new children against the accepted 20cm/material minimum. All existing
junction angle/distance, room, opening, Store, ACL and CAS guards remain.

The Python producer independently replays the named intent. The host ledger
compares the complete proposed floor/floors and root fields with JSON semantic
equality (bool is not number); Undo proves the exact forward result again.
This shares the existing named Merge ledger shape and Delete's value comparator.
The new receiver child/dependency records are canonically ordered before Python
validation; a suffix-ID regression and the 5000-edge witness cover that boundary.

Draw's two shared leaves have explicit editor-shared chunk ownership. Without
this, the newly nested Select import made Rollup internalize the editor facade
and the existing raw-URL retry ABI check failed. The check remains strict; the
normal build with unchanged named retry exports passes.
