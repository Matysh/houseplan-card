# Общий UI-кит диалогов

Контракт [#1007](https://github.com/Matysh/houseplan-card/issues/1007).
Переиспользуем существующие Lit-примитивы из src/editors/form-kit.ts. Состояние,
валидация, сохранение и HA-действия остаются у владельца формы.

## Компоновка

- formCard — заголовок и тело карточки.
- formSections([…]) — явные группы тела. Секция владеет разделителем и внешним
  ритмом: 18 px до и после него. Внутри группы — 12 px.
- field / fieldGrid / toggleRow / colorRow / formRow — внутреннее выравнивание
  поля. Их корневые элементы не добавляют внешних отступов секции.
- Компактный набор полей относится к одной группе. Группируйте подзаголовок
  и связанные поля одним Lit-шаблоном; не оставляйте отдельный заголовок перед
  условно отсутствующим содержимым.
- nothing, null, undefined, false и пустые массивы не создают секцию. Оставляйте
  условные позиции в исходном массиве: это сохраняет идентичность соседних
  контролов при исчезновении группы. Для произвольной перестройки порядка
  данные и черновики должны оставаться у владельца, а не в DOM.
- fieldGrid({stacked:true}) использует тот же контракт секций; обычная сетка
  сохраняет колонки. Онбординг пространства сохраняет исходный layout.

Пример:

~~~ts
body: formSections([
  field({label: nameLabel, htmlFor: 'name', control: nameInput}),
  extraEnabled ? field({label: extraLabel, control: extraInput}) : nothing,
  subsectionGroup,
])
~~~

Реальные компилируемые примеры — demo/dialog-ui-kit.ts. Не добавляйте
селекторы вида «все соседи после произвольного элемента» или компенсацию
отступов по ID поля. Общие правила — styles/dialog-composition.styles.ts;
специальные контентные сетки остаются в settings-dialogs.styles.ts.

## Токены и темы

| Токен | По умолчанию | Назначение |
|---|---:|---|
| --hpf-section-space | 18px | внешний интервал до/после разделителя |
| --hpf-group-space | 12px | интервал внутри группы |
| --hpf-help-gap | 4px | отступ Help от подписи или действия |
| --hpf-action-height | 44px | обычная кнопка |
| --hpf-action-radius | 7px | радиус обычной кнопки |

Цвета берутся из --hpf-* и токенов Home Assistant. Новую палитру в диалоге
не заводить. Плашки, Help и actions наследуют динамическую тему; тестируются
light/dark/custom. Размеры специальных иконочных кнопок и chips — существующие
варианты, а не уменьшенная обычная кнопка.

## Действия и помощь

settingsActionsCss из styles/settings-action.styles.ts — единый генератор
обычных, primary и danger кнопок для разных ShadowRoot (в том числе PDF и
Zigbee). settingsInteractiveCss — ссылки и компактные действия. Общие hover
фрагменты используются существующими settings/footer/confirmation правилами.
Layout-only стили списка устройств не задают второй paint или radius.

actionHelp(action, help) размещает действие и hp-help DOM-соседями.
disclosure({title,content,help?,triggerClass?}) делает то же для раскрытия.
Help внутри диалога — instant; у доступной иконки pointer, hover, focus и
всплывающая поверхность. Её нажатие не запускает действие, checkbox или
summary; отдельный hp-help не должен становиться потомком кнопки.

У field подпись/контрол связаны через htmlFor. У toggleRow сохраняются label,
доступное имя и зона ввода 44 px; видимый трек выравнивается по названию,
пояснение располагается ниже. Не уменьшайте сам input до высоты трека.
Длинная подпись переносится по словам, Help не отрывается на пустую строку.

## Спойлер

Вариант hpf-disclosure-compact сохраняет типографику технического статуса
(12 px, line-height 1.45, вторичный текст) с теми же индикатором, отступами,
клавиатурой и hover. Его использует пояснение неполных данных Zigbee.

disclosure — нативные details/summary с указателем раскрытия. Информационный
summary не получает класс btn. triggerClass допустим для существующего
выбора источника, визуально оформленного как действие. Переданный Help —
сосед details, а не потомок summary: его hover не меняет paint действия.
При наличии Help используется общая сетка; закрытое содержимое явно скрыто.
Нет ResizeObserver, измерения ширины кнопки или перестановок DOM для layout.

Открытость может оставаться нативной либо задаваться open/onToggle владельцем.
Смена значений других полей не сбрасывает открытый details. Используйте
клавиатурные Enter/Space и стандартную семантику. Появление содержимого имеет
короткую декоративную анимацию; reduced-motion её отключает. Нативное закрытие
не откладывает скрытие содержимого ради анимации.

## Миграция потребителей

| Потребитель | Что использует общий контракт |
|---|---|
| Общие настройки | явные группы всех разделов, поля/тумблеры/цвет, общий footer |
| Пространство | группы разделов и stacked grids; онбординг сохраняет прежний layout |
| Комната | группы полей/источников/размеров, общий footer и подтверждение отмены |
| Устройство | общие разделы, свет/значения, Help и действия |
| Пылесос | группы существующих полей, независимый Help выбора источника, disclosure диагностики |
| Радар | группы настроек и каждого канала, общий action-help; контентные координатные сетки сохранены |
| Zigbee | общие секции, disclosure ZHA/Z2M, кнопки из общего генератора в своём ShadowRoot |
| Помощь/обратная связь | существующая ui-dialog оболочка и общие actions/help/callouts |
| Список устройств | общие actions/hover; старое второе оформление tabs удалено |
| Правила иконок | общий ui-dialog/actions; контентная таблица сохраняется |
| Печать | тот же settingsActionsCss в корне PDF; выбор параметров не меняется |
| Подтверждения | существующие hp-dialog и общие action/footer состояния |

Новые параметры, цвет и компоновка карт пылесоса — #1002. Эта задача предоставляет
общие элементы, а не подменяет тот объём. Нативные HA picker и overlay registry
не заменяются; Escape сначала закрывает вложенное popup, сохраняя черновик.

## Проверка

node demo/smoke_dialog_ui_kit.mjs собирает галерею из действительных исходников
теми же Lit/Rollup-зависимостями. Синтетические данные, без доступа к настоящему HA.
Отчёт и кадры: artifacts/dialog-ui-kit-1007/. Статусы задач живут только в GitHub.

Там же сохраняются index.html и gallery.js — интерактивная страница тех же
компонентов, с переключением видимости группы и порядка. После запуска smoke
её можно открыть через обычный HTTP-сервер, например:
python -m http.server 8891 --directory artifacts/dialog-ui-kit-1007

Проверяются геометрия секций, пустая группа, сохранность соседнего input,
реальный hover Help и неизменившийся paint соседа, click/keyboard, native details,
reduced-motion, 1280/390/320 px и light/dark/custom темы. Unit
test/dialog-composition.test.mjs проверяет опускание вложенных пустых групп
и стабильную идентичность соседей. Реальные формы дополнительно покрываются
существующими settings smokes; одна галерея не доказывает интеграцию.

Для визуальной приёмки сопоставлять base/candidate и согласованные макеты
при одинаковых данных, теме, viewport, масштабе и состоянии. Допустима разница
сглаживания шрифта; ошибку геометрии она не оправдывает. Личные UI Lab-данные
и кадры остаются локальными. Состав выполненных проверок фиксируется в
handoff issue; не объявлять непроверенные состояния зелёными.

Kit остаётся в существующем lazy editor/onboarding графе; View-рендеринг
и формат данных не изменяются. Проверять gate:small, bundle:budget и lint:unused.
