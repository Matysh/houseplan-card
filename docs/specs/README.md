# Архив технических заданий

Здесь сохранены прежние ТЗ, на которые ссылаются продуктовые документы, код и
исторические ревью. Номер issue в имени файла помогает найти исходную задачу.
Другие старые ТЗ находятся в [legacy/specs](../../legacy/specs/).

Продуктовые контракты, решения и ограничения в этих файлах остаются полезным
контекстом. Их процессные предписания — прежние гейты, обязательные прогоны,
трейлеры и порядок передачи на ревью — не являются инструкциями для работы.
Текущую постановку и решения владельца сверять с самой issue.

Новые ТЗ находятся в разделе `## ТЗ` тела issue. Для подготовки использовать
[шаблон ТЗ](../process/SPEC-TEMPLATE.md); правила треков, подготовки и ревью
описаны только в корневом [PROCESS.md](../../PROCESS.md).

Документация #1105 подготовлена в этой ветке; переключение действующей
обвязки пока не разрешено. Чтение архива не требует запуска команд и не
создаёт дополнительного этапа проверки.
