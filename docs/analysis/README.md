# Исторические исследования и свидетельства

Здесь сохраняются разборы отдельных задач, измерения и результаты прогонов
на указанных в них версиях. Это справочный материал, который читают по теме
задачи, а не обязательный маршрут входа в проект.

Старые указания на полный gate, exact-SHA CI, pre-push или условия S7 описывают
процесс на дату исследования. Они не предписывают повторять команды сейчас.
Результаты, исходные данные и продуктовые выводы сохранены для сверки.

Правила работы — только в корневом [PROCESS.md](../../PROCESS.md).
Состояние подключения — в [отчёте переключения #1105](../../process-next/evidence/cutover-status.md).
