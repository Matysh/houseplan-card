`visual-comparison.json` содержит геометрию всех четырёх режимов в обеих темах:
header/stage/Properties совпадают; необработанных page errors нет.

## Большой план: сырые временные ряды

База: точный git archive dev `efa1b130fc69da8277de8bb013b08ea65b581010`,
собранный отдельно. Кандидат определён fingerprint в `motion-final.json`.
Playwright 1.62.0, Chromium headless-shell 151.0.7922.34/rev1234, WSL, 1280×900,
panel-host, обычный desktop CPU rendering; это не GPU-presented FPS.

`benchmark-modes.mjs` воспроизводит измерение на переданном корне сборки:
`node docs/evidence/1207/benchmark-modes.mjs <repo-root> <label>`.
Использованы канонические large-house-v1 и large-house-isometric-v1: 3 этажа,
60 комнат, 200 устройств, 100 проёмов, 500 декоров и 250 лестниц. Для каждого
профиля один прогрев и два измеряемых цикла plan → devices → decor → view.
Сохранены RAF серии, click-to-first-observable-motion, Long Tasks, счётчики
полных render и настоящих измерений header. Диагностические перехваты и
MutationObserver находятся только в скрипте замера.

Среднее по восьми измеренным переключениям на профиль:

| Профиль / версия | Первый видимый сдвиг, ms | Весь переход, ms | Полные render | Измерения header |
| --- | ---: | ---: | ---: | ---: |
| flat / base | 55.9 | 416.7 | 14.4 | 2 |
| flat / candidate | 89.9 | 445.7 | 3.2 | 2 |
| iso / base | 77.1 | 308.4 | 9.5 | 2 |
| iso / candidate | 79.6 | 483.4 | 3.9 | 2 |

Полный render исключён из обычных кадров flat motion; iso дополнительно делает
один атомарный commit проекции в середине fade. Рендеры подготовки/окончания
остаются. Header не измеряется в каждом кадре. Эти изменения сокращают работу
Lit, но не доказывают ускорение всех видимых переходов: подготовка и raster/layout
большого SVG остаются дорогими. Максимальный измеренный RAF gap 132.9 ms flat и
179.4 ms iso; стабильные 60 FPS **не подтверждены**. Раньше iso/View↔editor был
атомарным без нового fade, поэтому суммарное время не эквивалентно по поведению.
Новый hard gate производительности не вводился. Короткая серия зависит от
нагрузки хоста; исходные измерения сохранены полностью.

## Адресные проверки

Добавлены проверки реальных полей/preview узлов, scoped hints и геометрии тоста,
роста frame на четырёх поворотах, rapid retarget и отсутствия полного render на
кадрах. Проверены iso wide/narrow/reduced motion, fallback изометрии, сохранение
PPU/центра и zoom по этажам, reload zoom 24 → непрерывный шаг → явный Fit,
двухстрочный sourcePicker с 15 строками и прокруткой, selected/hover shared select,
реальная modal-toast ошибка и responsive panel header.

Room-fill regression воспроизвела вторую CSS-анимацию после общей timeline;
исправление сохраняет прежнюю заливку в покое и не даёт потемнения в переходе.
Тест теперь измеряет общую timeline для смены режимов, сохраняя CSS witness для
обычных изменений состояния/цвета. Старые записи `_viewModeSnap` в iso smoke
удалены вместе с отменённым механизмом восстановления прежней View камеры;
проверки fallback/refit/конфиденциальности сохранены.

Отдельно диагностически запускался старый `smoke_plan_snap_overlay.mjs`: он
падает на null.compareDocumentPosition также на неизменённой базе efa1. Этот
файл не изменялся; новая адресная проверка проверяет существующие/динамические
и свободные preview узлы настоящими событиями мыши. Старые `lint:unused`/
hostRefs/bundle-budget ограничения не являются S6 текущего PROCESS; полный
релизный набор, golden и HA E2E здесь не запускались.
