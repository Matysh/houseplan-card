# История изменений CI

Этот каталог хранит отчёты о прежних маршрутах CI и замерах их стоимости.
JSON-файлы и таблицы — исходные свидетельства конкретных прогонов, а не
конфигурация или требования нового процесса.

Упоминания обязательного Validate, проверки точного коммита, proof registry
и старых условий S7 относятся к процессу на дату отчёта. Запускать их по
инструкции из исторического документа не требуется.

Текущие правила — корневой [PROCESS.md](../../PROCESS.md). Состояние подключения
#1105 — в [отчёте переключения](../../process-next/evidence/cutover-status.md).
